# Установка МедКонтроля

Инструкция для тех, кто раньше не ставил программы через Docker. Обновление и откат описаны в [UPDATE.md](UPDATE.md).

## Что выбрать

| | Настольная версия | Версия для iPad | Серверная версия |
|---|---|---|---|
| Где работает | на одном компьютере (macOS, Windows) | на планшете iPad (iPadOS 17.4+), без сервера | на компьютере, который включён всегда: NAS, домашний сервер, старый ноутбук, VPS |
| С телефона | нет | сам планшет и есть устройство | да, через браузер, в том числе с отметкой приёма в один тап |
| Telegram-напоминания | пока приложение открыто | нет Telegram; системные напоминания всегда | всегда |
| Ночные бэкапы | нет, сохраняйте «Архив всех данных» сами | нет; копия в контейнере приложения + «Архив всех данных» через «Поделиться» | да, плюс второй диск и облако по желанию |
| Снимки DICOM, Apple Health | нет | нет | да |
| Что нужно поставить | только приложение | только приложение (сборка и подпись: [IPAD.md](IPAD.md)) | Docker |

Начать можно с настольной версии и потом переехать на сервер: «Настройки → Архив всех данных → Скачать архив», затем «Загрузить архив» в новой установке. Архив переносит историю и между iPad и другими редакциями.

**Настольная версия.** Установщики для macOS и Windows на странице [Releases](https://github.com/kubokot-tech/med-control/releases/latest); как скачать и запустить, написано в [README](../README.md#скачать-для-компьютера). Собрать самому: [DESKTOP.md](DESKTOP.md), раздел «Как собрать».

Дальше речь о серверной версии.

## Что понадобится

- Компьютер с 2 ГБ свободной памяти и 5 ГБ места на диске (под образы и первые годы данных; снимки КТ и МРТ займут больше).
- Docker: Docker Desktop на macOS и Windows, Docker Engine с плагином compose на Linux, Container Manager на Synology.
- Полчаса. Первая сборка занимает 5–15 минут, на слабом NAS дольше.

## Компьютер с macOS, Windows или Linux

1. Поставьте Docker:
   - **macOS:** [Docker Desktop](https://www.docker.com/products/docker-desktop/) и запустите его один раз (кит в строке меню).
   - **Windows:** [Docker Desktop](https://www.docker.com/products/docker-desktop/). Он попросит включить WSL 2, согласитесь и перезагрузите компьютер. Ещё нужен [Git для Windows](https://git-scm.com/download/win).
   - **Linux:** Docker Engine и плагин compose по [инструкции Docker](https://docs.docker.com/engine/install/) для вашего дистрибутива.
2. Откройте терминал (на Windows — PowerShell) и скачайте код:

   ```bash
   git clone https://github.com/kubokot-tech/med-control.git
   cd med-control
   ```

   Без git: на странице репозитория «Code → Download ZIP», распакуйте архив и откройте терминал в этой папке.
3. Запустите:

   ```bash
   docker compose up -d --build
   ```

4. Откройте в браузере http://localhost:3001. Дальше по порядку:
   - Первая страница: пароль, язык, часовой пояс и регион, кнопка «Начать работу».
   - Сразу после неё МедКонтроль один раз покажет **код восстановления пароля**. Запишите его: если забыть пароль, вернуть доступ можно только им. Кнопка «Продолжить настройку» включится, когда вы отметите, что код сохранён.
   - Затем пять шагов: кто ведёт историю и диагноз, протокол лечения, анамнез, ИИ, первые анализы. Любой шаг можно пропустить. Telegram настраивается потом в Настройках.

Файл `.env` для этого не нужен. Он понадобится, если захотите открыть сайт с телефона, перенести данные в свою папку или включить дополнительные службы.

**Где лежат данные.** База и загруженные файлы хранятся в томах Docker проекта `medcontrol`. Удаление папки с кодом их не трогает. Команда `docker compose down -v` их **стирает**, не выполняйте её. Ночные копии ложатся в папку `medcontrol-backups` рядом с папкой кода. Лучше держать их на другом диске: строка `BACKUP_DIR=/путь/на/другом/диске` в `.env`.

**Скрипты `scripts/*.sh`** (демо, восстановление) написаны для bash. На Windows запускайте их из Git Bash или WSL.

## NAS Synology

Подходят модели с процессором Intel или AMD и DSM 7.2 или новее. На моделях с процессором ARM работа не проверялась.

1. В «Центре пакетов» поставьте **Container Manager**.
2. Положите код на NAS: скачайте ZIP со страницы репозитория, распакуйте и загрузите папку через File Station, например в `docker/medcontrol`.
3. Чтобы сайт открывался с других устройств в доме, рядом с `docker-compose.yml` нужен файл `.env`. Проще всего создать его по SSH («Панель управления → Терминал и SNMP → включить SSH»):

   ```bash
   cd /volume1/docker/medcontrol
   printf 'BIND_ADDR=0.0.0.0\nAPP_URL=http://192.168.1.10:3001\n' > .env
   ```

   Вместо `192.168.1.10` подставьте адрес NAS в домашней сети.
4. Container Manager → «Проект» → «Создать». Укажите путь к папке, источник — существующий `docker-compose.yml`. Сборка займёт 10–20 минут.
5. Откройте `http://<адрес NAS>:3001`. Сайт открыт в домашнюю сеть, поэтому мастер первым делом спросит **код первого запуска**. Так установку не займёт тот, кто откроет страницу раньше вас. Код записан в журнале: Container Manager → «Проект» → medcontrol → контейнер gateway → «Журнал», строка «Код первого запуска: XXXX-XXXX». По SSH то же самое показывает команда `sudo docker compose logs gateway | grep "Код первого запуска"`.
6. Бэкапы по умолчанию ложатся в `docker/medcontrol-backups`. Если в NAS два диска или подключён USB-диск, задайте в `.env` `BACKUP_DIR=/volume2/...` и пересоздайте проект.

## Доступ с телефона

Сайт работает в браузере телефона. В Safari «Поделиться → На экран „Домой“» добавляет его как приложение. Есть три способа до него добраться, от простого к сложному.

### Только дома, по Wi-Fi

В `.env` должны быть `BIND_ADDR=0.0.0.0` и `APP_URL=http://<адрес компьютера в сети>:3001`. После правки выполните `docker compose up -d`. Телефон в той же сети откроет этот адрес. Вне дома доступа нет. Вход по Face ID (passkey) так не заработает: браузеры дают его только по HTTPS.

### Отовсюду, только своим устройствам: Tailscale

[Tailscale](https://tailscale.com) соединяет ваши устройства в частную сеть. Сайт не виден из интернета, работает HTTPS, работает вход по Face ID. Бесплатного тарифа хватает.

1. Поставьте Tailscale на компьютер с МедКонтролем (на Synology — пакет из «Центра пакетов») и на телефон, войдите в одну учётную запись.
2. На компьютере с МедКонтролем включите HTTPS-адрес:

   ```bash
   tailscale serve --bg 3001
   ```

   Команда напечатает адрес вида `https://имя-компьютера.имя-сети.ts.net`.
3. В `.env` укажите этот адрес: `APP_URL=https://имя-компьютера.имя-сети.ts.net`. Строку `BIND_ADDR` оставьте как есть или удалите: Tailscale подключается к МедКонтролю изнутри компьютера. Затем выполните `docker compose up -d`. Если мастер первого запуска ещё не пройден, он спросит код первого запуска (см. «Если что-то не так»).
4. На телефоне с включённым Tailscale откройте этот адрес.

### Отовсюду, по своему домену: Cloudflare Tunnel

Подходит, если нужен обычный адрес без приложения на телефоне (например, чтобы открыть с чужого компьютера). Нужен свой домен, подключённый к Cloudflare. Учтите: сайт виден из интернета, а трафик расшифровывается на серверах Cloudflare.

1. Cloudflare → Zero Trust → Networks → Tunnels: создайте туннель и поставьте `cloudflared` на компьютер с МедКонтролем по подсказке.
2. В туннеле добавьте публичное имя, например `med.ваш-домен.ru`, с сервисом `http://localhost:3001`.
3. В `.env`: `APP_URL=https://med.ваш-домен.ru`, затем `docker compose up -d`. Если мастер первого запуска ещё не пройден, он спросит код первого запуска.
4. Настоятельно советуем добавить Cloudflare Access (Zero Trust → Access → Applications) с входом по одноразовому коду на вашу почту. Тогда посторонний не увидит даже страницу входа.

Свой сервер с пробросом порта и HTTPS-прокси описан в [ARCHITECTURE.md](ARCHITECTURE.md), раздел про путь запроса.

## После установки

- Блок «С чего начать» на главной: протокол лечения, анамнез, помощник ИИ, Telegram.
- «Настройки → Пациент и анамнез»: ФИО и диагноз для шапки отчёта врачу.
- «Анализы → Загрузить»: первые PDF. Если лаборатории нет среди известных, «Ввести вручную» или помощник ИИ; образец бланка поможет добавить лабораторию в следующих версиях.
- Проверьте на следующее утро, что бэкап прошёл: «Настройки → Для администратора сервера → Бэкапы». Копия делается ночью в 03:30 по часам службы бэкапов, а не по часовому поясу, который вы выбрали в программе. Часы службы задаёт переменная `TZ`, по умолчанию `Europe/Moscow`. Чтобы копии шли по вашему времени, добавьте в `.env` свой пояс, например `TZ=Europe/Berlin`, и выполните `docker compose up -d`.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| `http://localhost:3001` не открывается | `docker compose ps`: все службы должны быть `running` или `healthy`. Журнал: `docker compose logs gateway --tail 50`. Первая сборка и первый запуск gateway (миграции) идут несколько минут. |
| Порт 3001 занят | В `.env`: `APP_PORT=3002`, `docker compose up -d`, открыть http://localhost:3002. |
| Мастер просит код первого запуска | `docker compose logs gateway \| grep "Код первого запуска"`. Код меняется при каждом перезапуске gateway. |
| Вместо данных снова мастер первого запуска | Установка запустилась с другим именем проекта и не видит прежние тома. `docker compose ls` и `docker volume ls` покажут старое имя, его нужно задать в `.env`: `COMPOSE_PROJECT_NAME=<старое имя>`. Подробнее в [UPDATE.md](UPDATE.md). |
| Забыт пароль | На экране входа «Забыли пароль?» и код восстановления из мастера. |

Остальные неполадки разобраны в [OPERATIONS.md](OPERATIONS.md), восстановление из бэкапов — в [RESTORE.md](RESTORE.md).
