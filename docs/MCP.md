# Доступ для ИИ-агентов (MCP)

Model Context Protocol позволяет внешним ИИ-агентам (Claude Desktop, ChatGPT, Cursor и другим клиентам MCP) читать
данные МедКонтроля и, если разрешено, добавлять заметки и записи дневника. Это медицинские данные, поэтому доступ
по умолчанию выключен и устроен так, чтобы его было трудно открыть случайно и легко закрыть.

## Защита

- **Выключено по умолчанию.** Пока доступ выключен, адрес `/api/gateway/mcp` отвечает 404, будто его нет.
- **Включение только с подтверждением.** В Настройках → «Доступ для ИИ-агентов (MCP)» пользователь читает предупреждение
  (какие данные видит агент, что они уходят туда, где работает его модель, что токен — как пароль), ставит галочку
  и вводит пароль; без галочки сервер включить не даёт (`mcp_ack_required`). Новый токен тоже требует пароль:
  украденной сессии для этого мало.
- **Запрет на уровне сервера.** `DTC_MCP=off` в `.env` запрещает включение совсем, в интерфейсе об этом сказано.
- **Отдельный токен на каждого агента**, у токена права: «только чтение» или «чтение и запись». Токен показывается
  один раз, в базе хранится только его SHA-256 (`mcp_tokens`). Не больше 10 действующих токенов.
- **Выключение отзывает все токены.** Повторное включение не возвращает старые агенты. «Выйти везде» и смена пароля
  тоже отзывают все токены.
- **Журнал** (`mcp_audit`): время, токен, метод, инструмент, успех или код отказа. Данные в журнал не пишутся.
- **Telegram**: сообщение при включении, выключении и создании токена.
- **Ограничение частоты**: 120 вызовов в минуту на токен.
- **Проверка Origin**: запрос со страницы другого сайта отклоняется (защита от DNS rebinding и CSRF); агенты Origin не шлют.
- **Без файлов, секретов и настроек**: инструменты отдают только данные пациента в JSON; вложения — списком имён, без содержимого.
- Токен агента не открывает интерфейс и обычное API: он работает только на `/mcp`.

## Подключение

Адрес: `https://<ваш адрес>/api/gateway/mcp`, транспорт Streamable HTTP (один JSON-ответ на запрос, без потока событий
и без сессий), токен в заголовке `Authorization: Bearer mcp_…`. Пример настройки клиента:

```json
{
  "mcpServers": {
    "medcontrol": {
      "type": "http",
      "url": "https://medcontrol.example.com/api/gateway/mcp",
      "headers": { "Authorization": "Bearer mcp_…" }
    }
  }
}
```

Сервер должен быть доступен агенту: облачному агенту — из интернета по HTTPS, локальному — в домашней сети.

## Инструменты

| Инструмент | Права | Что отдаёт или делает |
|---|---|---|
| `get_patient_profile` | чтение | профиль пациента одним текстом, как у встроенного помощника |
| `list_lab_markers` | чтение | показатели справочника, число результатов, дата последнего |
| `get_lab_results` | чтение | результаты (ключ, период, лимит) с действующей нормой и нормой бланка, в СИ |
| `get_medications` | чтение | препараты, дозы, расписание и отметки приёма за N дней |
| `get_diary` | чтение | записи дневника за период |
| `get_appointments` | чтение | приёмы у врача и вопросы к ним |
| `get_history` | чтение | вехи истории болезни, имена файлов |
| `get_imaging` | чтение | исследования, очаги, размеры, RECIST |
| `get_contacts` | чтение | врачи и контакты |
| `search` | чтение | поиск по всему |
| `add_note` | запись | заметка с тегом «ии-агент» (на английском `ai-agent`) и источником «MCP: <имя токена>» |
| `add_diary_entry` | запись | значения в дневник за прошедший или сегодняшний день, заметка дописывается |

## Как устроено

- `gateway/src/lib/mcpAccess.js` — включение, токены, журнал, ограничение частоты.
- `gateway/src/lib/mcpTools.js` — инструменты: JSON-схема для агента, zod-проверка аргументов, обработчик.
- `gateway/src/lib/mcpServer.js` — JSON-RPC: `initialize`, `ping`, `tools/list`, `tools/call`; уведомления получают 202.
- `gateway/src/routes/mcp.js` — `POST /mcp` и настройки: `GET`/`PUT /settings/mcp`, `POST`/`DELETE /settings/mcp/tokens`.
- Миграция 034: `mcp_tokens`, `mcp_audit`. Тест: `gateway/test/integration/mcp.test.js`.
