# МедКонтроль: что это и как этим пользоваться

МедКонтроль (MedControl) — личная история лечения для одного пациента. Он хранит анализы, приём препарата, снимки, вехи болезни, дневник самочувствия, приёмы у врача и капельницы, следит за опасными значениями, напоминает в Telegram и умеет объяснять данные через ИИ. Данные хранятся у вас: на своём сервере (NAS, домашний сервер или VPS), откуда снаружи открыт только сайт по HTTPS, или на одном компьютере в [настольной версии](#настольная-версия). Что и когда идёт наружу, описано в разделе [«Что уходит наружу»](#что-уходит-наружу).

Документ описывает, что есть на каждом экране и что делают кнопки. Как это устроено внутри — в [ARCHITECTURE.md](ARCHITECTURE.md), как обслуживать — в [OPERATIONS.md](OPERATIONS.md), как восстановить после поломки — в [RESTORE.md](RESTORE.md). Что ещё не сделано — в конце этого файла и в [ROADMAP.md](ROADMAP.md).

## Один обычный день

- **Утром** Telegram напоминает, что препарат сегодня ещё не отмечен. Кнопки «Принято» и «Пропустить» прямо в сообщении, можно и просто написать боту «принято».
- **Пришёл PDF из лаборатории.** Отправляете его боту или перетаскиваете на сайт. Знакомый бланк разбирается сразу, незнакомый разбирает ИИ, а вы проверяете строки. АЛТ из разных лабораторий попадает в один ряд, г/дл пересчитываются в г/л. Если значение перешло порог из протокола, тревога приходит в Telegram в течение минуты.
- **Вечером** одна строка боту: «давление 135/85, усталость 2, вес 71». Давление и вес могут приходить с iPhone сами, через Apple Health и приложение Health Auto Export.
- **Перед приёмом** нажимаете «Подготовить вопросы». ИИ читает всё, что накопилось с прошлого визита, и раскладывает по разделам: коротко о периоде, сказать врачу, спросить, показать или принести. Этот список можно поставить первой страницей отчёта для врача.
- **После приёма** прикладываете заключение и коротко записываете, что сказал врач. Файл ложится в историю болезни как консультация. Текст из PDF достаётся сам, фото или скан распознаётся кнопкой «Достать текст», без ИИ. После этого документ виден поиску и ИИ.

## Навигация

На телефоне внизу четыре вкладки и кнопка «Ещё». На компьютере то же самое сбоку, и там же ещё пять разделов: история болезни, дневник симптомов, капельницы и инъекции, приёмы у врача и отчёт для врача; в «Ещё» остаётся остальное. Под знаком на компьютере написано название.

| Пункт | Адрес | Что там |
|---|---|---|
| Сегодня | `/` | приветствие, приём за сегодня, «Как вы сегодня?», хорошие новости, что требует внимания, лента событий |
| Анализы | `/labs/…` | сводная таблица, графики, документы, загрузка PDF, ручной ввод, нормы |
| Препараты | `/meds` | основной препарат и поддержка: доза, календарь приёма, история изменений дозы, напоминания |
| Снимки | `/imaging` | исследования, очаги, RECIST, архив DICOM, срезы |
| Ещё → История болезни | `/history` | вехи с файлами, пакетная загрузка документов, текст документов для ИИ |
| Ещё → Дневник симптомов | `/symptoms` | самочувствие, побочки, давление, температура, вес |
| Ещё → Капельницы и инъекции | `/infusions` | справочник препаратов со способом введения, журнал сеансов и курсы |
| Ещё → Заметки и исследование | `/notes` | рабочая тетрадь о болезни: ссылки, статьи, мысли, импорт .md из других ИИ, разбор с ИИ |
| Ещё → Приёмы у врача | `/consults` | запланированные визиты, вопросы от ИИ, отчёт врача |
| Ещё → Врачи и контакты | `/contacts` | телефоны, почта, адреса врачей и регистратур |
| Ещё → Уведомления | `/alerts` | тревоги по правилам |
| Ещё → Отчёт для врача | `/report` | PDF за период с пресетами, файл для ИИ |
| Ещё → Поиск по всему | `/search` | полнотекстовый поиск по заметкам, вехам, текстам документов, снимкам, приёмам, контактам, дневнику, капельницам, ответам ИИ, показателям и препаратам |
| Ещё → Настройки | `/settings` | список разделов: протокол, пациент и анамнез, нормы, Telegram, Apple Health, помощник ИИ, доступ для ИИ-агентов, вход и защита, язык и регион, архив всех данных; бэкапы и лаборатории в разделе для администратора |
| Ещё → Выйти | | стирает сессию в этом браузере (токен остаётся действительным до конца срока; для потерянного телефона — «Выйти везде» в Настройках) |

Сайт можно поставить на экран «Домой» телефона как приложение (PWA-манифест и service worker есть). Без связи с сервером показывается заглушка «Нет связи с сервером».

Пока в разделе нет записей, он показывает, что здесь появится и с чего начать; на «Сегодня» и в «Документах» сразу есть кнопка загрузки анализов.

## Первый запуск

Если пароль ещё не задан (нет `DTC_PASSWORD` в `.env` и первый запуск не пройден), вместо входа открывается страница первого запуска: пароль дважды (минимум 10 символов; не одни цифры, не ряд клавиш или букв подряд и не распространённый пароль вроде «password2024»), язык, часовой пояс (по умолчанию пояс браузера) и регион (по языку браузера). «Начать работу» сохраняет их и входит. Сразу после этого МедКонтроль один раз показывает **код восстановления пароля**: его можно скопировать или скачать файлом, а кнопка «Продолжить настройку» включается после отметки, что код сохранён. Пароль хранится хэшем scrypt. Страница срабатывает один раз; пароль потом меняется в Настройках → «Вход и защита», а если он забыт, кодом восстановления.

Если сайт открыт не только на этом компьютере (`APP_URL` с именем или адресом не `localhost`, либо `BIND_ADDR` не `127.0.0.1`), мастер первым полем спрашивает **код первого запуска**: без него установку занял бы тот, кто первым откроет страницу. Код вида `XXXX-XXXX` gateway при старте пишет в журнал (`docker compose logs gateway | grep "Код первого запуска"`) и в файл `setup-code.txt` в папке данных; после мастера файл удаляется. Неверный код считается как неудачная попытка входа. Локальной установке и настольной версии код не нужен; но если запрос пришёл с адреса из интернета (туннель к установке с настройками по умолчанию), код спрашивается всё равно. `DTC_SETUP_CODE=on|off` в `.env` включает или выключает его принудительно. Неверный код блокирует только адрес, с которого его вводили. Сверх этого есть общий предел для адресов из интернета: 100 неверных кодов за десять минут, и интернет ждёт десять минут; этот компьютер и домашняя сеть в него не входят.

После кода восстановления открывается `/welcome`, пять шагов, каждый можно пропустить: кто ведёт историю, как обращаться и диагноз; протокол лечения (первым в списке и уже отмечен «Общий контроль анализов», он подходит для любого долгого наблюдения; «Дальше» его сохраняет, «Пропустить» оставляет выбор на потом); анамнез текстом или из документа (PDF, фото, текстовый файл: текст читается на месте, файл не сохраняется, `POST /settings/anamnesis/extract`); ИИ с тем, что он даёт, что получает, и пошаговой инструкцией для OpenRouter, Claude, ChatGPT и GigaChat, ключ проверяется запросом, не прошедший ключ не сохраняется (DeepSeek, YandexGPT и своя модель подключаются потом в Настройках → «Помощник ИИ»); первые анализы: один или несколько PDF; если в бланке нужно проверить строки, шаг предлагает добавить его на вкладке «Загрузить». Ключи ИИ хранятся в базе; значения из `.env`, если заданы, важнее. В конце экран «Готово»: сколько показателей загружено и какие значения вне нормы лаборатории, кнопка «Открыть МедКонтроль» ведёт на «Сегодня». Что пропущено, остаётся в списке «С чего начать» на главной. Telegram в эти шаги не входит, он настраивается в Настройках. Если пароль задан в `.env`, страницы первого запуска и этих шагов нет: то же самое настраивается в Настройках и по списку «С чего начать».

## Вход и passkey

Экран входа: заголовок «История лечения — целиком.», короткое описание и кнопка «Войти в МедКонтроль». Два способа войти. **«Войти по ключу»**: без пароля, телефон сам предлагает сохранённый passkey (Face ID / Touch ID); ключ это владение телефоном плюс биометрия, поэтому пароль не нужен. **Пароль**: логина нет, пользователь один; пароль задаётся в мастере первого запуска или в `.env` (`DTC_PASSWORD`), затем шаг «Подтвердить ключом», если ключи есть. Пользователь один. После пяти неверных паролей с одного адреса вход с него блокируется на минуту, каждая следующая ошибка удваивает блокировку (до часа). Общий предохранитель на все адреса срабатывает после 25 неверных паролей и закрывает вход по паролю для новых устройств. Устройство, с которого уже входили, браузер помнит, и для него действует только блокировка его адреса; вход по ключу общий предохранитель тоже не закрывает, а неудачная попытка входа по ключу не считается ошибкой. Так посторонний не может перебором паролей запереть владельца. Проверка пароля в Настройках (смена пароля, ключи, MCP) от чужих попыток не зависит. Адрес клиента передаёт edge (Caddy доверяет только прокси из домашней сети), так что блокируется атакующий, а не весь роутер.

Если в Настройках зарегистрирован хотя бы один passkey (Face ID / Touch ID / ключ в связке iCloud или Google), после пароля появляется шаг «Подтвердить ключом». Ключ привязан к домену из `APP_URL`; дополнительные адреса можно перечислить в `WEBAUTHN_ORIGINS`. Если все ключи потеряны, `DTC_MFA=off` в `.env` временно отключает второй шаг: войдите, удалите старые ключи, добавьте новый, верните `DTC_MFA=on`.

Сессия живёт `JWT_TTL` (по умолчанию 30 дней) и хранится в браузере. «Выйти» в меню «Ещё» стирает её только в этом браузере, сам токен продолжает действовать до конца срока. «Выйти везде» в Настройках отзывает все выданные токены.

## Сегодня

Заголовок — день недели и дата, над ним приветствие по времени суток: «Добрый вечер, Анна», рядом фото пациента или инициалы. Фото добавляется в карточке пациента, уменьшается в браузере и остаётся только в МедКонтроле: в ИИ и в отчёт врачу не попадает. Как обращаться, задаётся в Настройках → «Пациент и анамнез»: имя («Анна») и поле «Дневник ведёт» (сам пациент или близкий человек). Если ведёт близкий человек, приветствие без имени, а вопрос о самочувствии звучит так: «Как мама сегодня?». Дальше:

- **С чего начать · 2 из 4.** Пока не всё настроено: протокол лечения, анамнез, помощник ИИ, Telegram — у каждого пункта зачем он нужен и ссылка на раздел Настроек. Блок можно скрыть на этом устройстве, он исчезает сам, когда все четыре пункта готовы. Apple Health и ключи входа необязательны и в список не входят.
- **Терапия.** Карточка препарата: «День N терапии», «N дней приёма подряд», кнопка с текущей дозой «Принято: 24 мг» и рядом «пропустить». После отметки «Принято в 10:42» и «отменить». Под кнопкой обычное время приёма и «вчера в 10:42», если вчера приём отмечен. Дни без отметки собраны в «Требует внимания». На новой установке, пока отметок нет, серия не показывается.
- **«Как вы сегодня?»** Самочувствие одним касанием: плохо, так себе, нормально, хорошо, отлично, та же шкала 1–5, что в дневнике. Записывается только самочувствие за сегодня, остальное в дневнике не трогается; выбор можно поменять до конца дня.
- **Тихие вехи.** «100 дней терапии», «Год с начала терапии», «100 дней приёма подряд»: одна строка на несколько дней, её можно скрыть. В Настройках → «Пациент и анамнез» вехи и серия дней выключаются совсем.
- **Тихий режим.** Две недели после вехи с отметкой «плохая новость» приложение не показывает серию дней и вехи (календарь приёмов остаётся, это данные). На главной короткая строка с кнопкой «Вернуть»; новая плохая новость снова включает режим.
- **Хорошая новость.** За последние 60 дней: последняя веха с отметкой «хорошая новость» и ключевой показатель, вернувшийся в норму (последний результат в норме, предыдущий был вне её). Не больше трёх, каждую можно скрыть.
- **Приём у врача.** Ближайший запланированный визит: «Сегодня», «Завтра» или «Через N дн.», врач, дата и время, ниже «Вопросы к приёму готовы» либо «Вопросы к приёму можно подготовить заранее»; карточка ведёт в Приёмы у врача. Если дата прошла, а приём не закрыт, появляется вопрос «Как прошёл приём 3 ноября?» с подсказкой загрузить отчёт врача или отметить, что приём прошёл.
- **Требует внимания.** Открытые тревоги, ключевые показатели вне нормы (с датой последнего анализа, «выше нормы»/«ниже нормы»), и «Отметить приёмы за неделю?» с числом дней без отметки. Каждая карточка ведёт на нужный экран.
- **Лента.** События по дням (Сегодня, Вчера, дальше даты): приём препарата (принят/пропущен/пауза), «Загружен документ» с числом показателей и «N вне нормы», вехи, изменения дозы, капельницы, оценки ИИ. «Показать ещё» подгружает старые.

## Анализы

Экран с четырьмя вкладками и кнопками «ИИ: итог месяца» и «Нормы». На телефоне вкладки компактнее, на самых узких экранах активная вкладка сама прокручивается в видимую область.

### Загрузить

Перетащите один или несколько PDF в область «Нажмите или перетащите PDF-файлы сюда» и нажмите «Загрузить N файлов». Каждый файл проходит путь:

1. Считается SHA-256. Если такой файл уже загружали — статус «Дубликат», ничего не меняется.
2. Gateway сам читает текстовый слой PDF и пробует встроенные парсеры, без ИИ и без интернета (Python-сервис `ingestion` оставлен в запасе, см. [LAB-PARSERS.md](LAB-PARSERS.md), «Два движка»). Сейчас узнаются бланки четырёх лабораторий: **МКНЦ**, **Хеликс**, **Хадасса** (Москва) и **ДНКОМ**; список виден на вкладке «Загрузить» и в Настройках → «Для администратора сервера». Как добавить свою лабораторию: [LAB-PARSERS.md](LAB-PARSERS.md).
3. Если формат не узнан и задан ключ ИИ, документ разбирает модель (основная). Она возвращает лабораторию, дату, и построчно: название показателя как в документе, результат, единицы, референс. Статус файла становится «Разобрано ИИ, нужна проверка», раскрывается панель проверки: поля «Лаборатория» и «Дата», таблица строк (Тест / Значение / Ед. / Реф), у каждой строки «Убрать строку», внизу «Сомнения модели», если они есть, и кнопка «Сохранить N показателей». До нажатия ничего не сохраняется, черновик лежит в `/data/uploads/pending`.
4. При сохранении названия показателей приводятся к единому каталогу (АЛТ из любой лаборатории попадает в один ряд `ALT`), единицы — к канонической единице маркера (г/дл → г/л, мг/дл → мкмоль/л и т. п.; несовместимые пары остаются как есть), качественные строки вроде «цвет мочи» в результаты не попадают, но хранятся в сыром виде. «10*9/л» читается как 10⁹/л. «Лейкоциты» и «Эритроциты» уходят в мочевую серию только при единицах кл/мкл, клет/мкл, количество/мкл или «в п/з»; «млн/мкл», «тыс/мкл», «10*3/мкл» остаются кровью. Сразу проверяются правила тревог.

Если ключа ИИ нет и формат не узнан — «Формат лаборатории не распознан встроенными парсерами, а ключ ИИ не задан…». Если файл пришёл через Telegram и требует проверки, ссылка из сообщения бота открывает эту же вкладку с уже подставленным черновиком («из Telegram»).


**Ввести вручную** (под областью загрузки): бумажный бланк или лаборатория без парсера, без ИИ. Дата анализа, лаборатория по желанию, строки «показатель — результат — единица — норма». Показатель выбирается из справочника (единица подставляется в выбранных в Настройках единицах) или «Другой показатель…» с названием как в бланке. Результат пишется как в бланке: «5,5», «<0,6», «отрицательно»; единицу можно поменять, значение пересчитается. Норму вводить не обязательно. Сохраняется как разобранный бланк: нормы, тревоги, лента, сводная; в документах — пометка «введено вручную», без PDF.

**Образец бланка.** Если вашей лаборатории нет в списке, на вкладке «Загрузить» и в Настройках → «Для администратора сервера» есть кнопка «Выбрать PDF бланка», а у файла, который не удалось разобрать сразу, «Подготовить образец бланка». Подходит только PDF с текстовым слоем: сканы отклоняются, картинки не принимаются. Приложение готовит текст без личных данных: незнакомые слова закрыты, все цифры случайные, даты и время одни и те же, сам PDF никуда не уходит. Текст можно прочитать, поправить и скопировать («Скопировать текст»). Отправка («Отправить») есть, только если задан адрес приёма `LAB_SAMPLES_URL`: нужно вписать название лаборатории и поставить галочку «Текст прочитан, личных данных в нём нет». Уходят название, текст и версия программы. Как устроено: [LAB-PARSERS.md](LAB-PARSERS.md), «Образец бланка».

### Сводная

Таблица «показатель × месяц». Если за месяц несколько анализов, по умолчанию показывается «Худшее за месяц»: значение, сильнее всего выходящее за норму, а при всех значениях в норме наибольшее; переключатель «Последнее» показывает самый свежий анализ месяца. Маленькая цифра у значения это число анализов за месяц, при наведении дата показанного. Экспорт в Excel и PDF использует тот же выбор. Фильтры: «Кровь»/«Моча», период «3м»/«6м»/«12м»/«Всё» или «С месяца»/«По месяц». Значения вне нормы подсвечены. Норма у показателя одна: из справочника МедКонтроля, своя или из бланка ([REFERENCE-RANGES.md](REFERENCE-RANGES.md)). Нажатие на показатель открывает карточку: последнее значение, «норма 4–10», «выше нормы на 12%», справка «Что это за показатель» и мини-график.

Кнопка «Экспорт» открывает лист с описанием текущих фильтров и галочкой «взять всё время»: **Excel** (три листа: «Сводная» с подсветкой вне референса, закреплёнными заголовками и примечаниями о числе анализов за месяц; «Все результаты» построчно с автофильтром; «Справочник» показателей), **PDF для врача** в стиле отчёта (кровь и моча отдельно, норма, подсветка; при длинном периоде альбомная ориентация и таблицы по 10 месяцев), **CSV** (строка на результат, разделитель «;», открывается в Excel и Numbers, годится для ИИ) и **JSONL**. Все форматы повторяют сводную с экрана: то же значение за месяц («худшее» или «последнее»), те же названия и референсы.

### Динамика

График одного показателя по времени с полосой нормы. Под значением «Норма ≤ 33 (справочник)» или «(своя)», «(по бланку)», и ссылка «изменить норму»: справочник, как в бланке лаборатории или своя норма (одну границу можно не задавать). Выбор показателя вверху. Ссылка «сырые значения» показывает исходные строки как в документах (до приведения единиц).

### Документы

Список загруженных PDF: лаборатория, дата, число показателей, сколько вне нормы. Страница документа: таблица результатов, сам PDF, и блок «Комментарий от ИИ» — кнопка «Отправить в ИИ» (потом «Спросить заново»). Модель видит показатели документа, прошлые значения тех же показателей и терапию; пишет «Главное / Вне нормы / Динамика / Обсудить с врачом». Ниже поле «Уточнить у ИИ…» для вопросов по этому документу, и у каждого ответа раскрывашка «Что видела модель».

### ИИ: итог месяца

Кнопка в шапке Анализов открывает список месяцев с анализами. «Оценить <месяц>» просит модель (основную) оценить все анализы месяца как единую картину, с историей ключевых маркеров за полгода и последними известными значениями даже тех, что в этом месяце не сдавались. Результат хранится и как оценка, и как веха «Оценка ИИ» в Истории болезни, ленте и отчёте врачу. «Оценить заново» перезаписывает. Тут же можно задать уточняющий вопрос.

## Препараты

Два слоя. **Основной (системный) препарат**: большая кнопка «Принято сегодня», календарь задним числом, история доз, серия за 4 недели, напоминания в Telegram (время меняется в Настройках → Telegram). **Поддержка**: список остальных постоянных препаратов (левотироксин, гепатопротекторы и т. п.), у каждого доза, «раз в день», правила приёма (например, «натощак за 30 минут до завтрака»), своё время напоминания в Telegram, отметка «Принято сегодня» / «Пропустить», календарь и полоска за две недели. «Добавить» создаёт препарат с ролью, дозой, датой начала; «Изменить» правит правила и напоминание; «Отменить препарат» завершает приём, история остаётся. Если приёмов несколько в день («Раз в день: 2»), каждый отмечается отдельно: «1-й принят», потом «2-й принят»; рядом «сегодня: 1 из 2, в 09:10» и «Отменить последний». Назначение и отмена попадают в ленту. В профиле для ИИ, отчёте врачу и файле для ИИ поддерживающие препараты перечислены отдельной строкой; приверженность считается только по основному. Если основного препарата нет, серия пустая.

Один основной препарат (например, диеногест, такролимус или ленватиниб) и сколько угодно препаратов поддержки. У каждого своё расписание: каждый день, по дням недели (например, метотрексат по понедельникам) или раз в N дней, считая от даты начала («Как часто» в форме препарата). В дни без приёма напоминания не приходят, календарь и серия не считают их пропуском; на главном экране вместо «Принято» — «Сегодня приёма нет · следующий …» с возможностью отметить приём вне графика. Экран:

- **Карточка дозы**: «Сейчас 2 мг», «Принято сегодня» / «Пропустить» (или «Принято сегодня в 10:42»). При нескольких приёмах в день: «1-й приём принят», после него «Сегодня отмечено 1 из 2: в 09:10» и «2-й приём принят», «Пропустить», «Отменить последний»; когда отмечены все — «Сегодня принято 2 из 2: в 09:10, 21:05». На главном экране так же.
- **Изменить дозу**: «Новая доза, мг», «С какого дня», «Причина». История изменений хранится и попадает в профиль для ИИ и в отчёт врачу. Доза с будущей даты не меняет текущую: до этого дня карточка показывает прежнюю. В каждой отметке приёма доза берётся на дату приёма, поэтому отметка задним числом или из Telegram за вчера получает ту дозу, что действовала в тот день.
- **Календарь приёма**: месяц по дням, цвета — принято / пропущено / пауза / без отметки. Нажатие на день открывает выбор «Принято», «Пропущено», «Пауза», «Очистить». При нескольких приёмах в день статус из календаря («Принято», «Пропущено», «Пауза») ставится на все приёмы дня, а день, где приняты не все, показан светлой клеткой «не все приёмы». Можно выделить период «С … По …» и проставить один статус на все дни (например, паузу терапии на две недели по гепатотоксичности). «Пауза» — это не пропуск: такие дни не считаются ни принятыми, ни пропущенными.
- **Журнал**: последние отметки с временем и откуда пришла отметка (сайт или Telegram).

Отметка на каждый приём: у препарата «раз в день» одна на день, у «2 раза в день» две. Когда отмечены все приёмы дня, следующая попытка отвечает «уже отмечен, изменить можно в календаре». День считается принятым, только если приняты все приёмы; день, где приняты не все, в серии, отчёте врачу и профиле для ИИ идёт отдельно («приняты не все дозы дня») и прерывает серию, если он уже прошёл. Сегодняшний день с частью приёмов серию не прерывает. Напоминание в Telegram: первое — пока за день ничего не отмечено, повтор в 20:00 — пока отмечены не все приёмы («отмечено 1 из 2»); кнопка «✅ Принято» в Telegram отмечает следующий приём.

## Снимки

Список исследований по датам: метод (КТ, МРТ, ПЭТ-КТ, УЗИ, Рентген), область, заключение, оценка врача (уменьшение / стабилизация / рост / полный ответ / без оценки), папка с диском.

- **Новое исследование**: «Дата», метод, «Область», «Заключение», «Папка с диском (DICOM)».
- **Разобрать заключение**: загрузите PDF/фото заключения или вставьте «Текст заключения (если нет файла)», нажмите «Разобрать». Модель заполняет метод, область, дату, заключение своими словами документа, оценку (PR/SD/PD/CR/NA), список очагов с размерами (и прошлыми размерами, если приведены), флаг новых очагов и сомнения. Результат подставляется в форму исследования и сохраняется как первый комментарий ИИ к нему. Без ключа кнопка отключена («Нужен ключ ИИ»).
- **Очаги и RECIST 1.1**. У каждого исследования — размеры очагов в мм. Очаг может быть «Целевой очаг, участвует в сумме» или «Нецелевой» (нажатие переключает). Для целевых считается сумма наибольших диаметров, сравнивается с исходной (первое исследование) и с надиром (наименьшая сумма): PR — сумма ≤ 70% от исходной, PD — ≥ 120% от надира и прирост ≥ 5 мм, CR — сумма 0, иначе SD. КТ и ПЭТ-КТ считаются вместе, МРТ отдельно, чтобы очаги с разных методов не складывались. Под исследованием: «Сумма целевых очагов 23 мм · −35% к исходному · RECIST: частичный ответ».
- **Комментарий от ИИ** к исследованию («Отправить в ИИ»): объясняет заключение, термины, динамику по сравнению с прошлыми исследованиями той же зоны. Если к исследованию приложены картинки срезов, модель их видит (до 4) и описывает отдельным абзацем, осторожно и без диагнозов. Ниже — вопросы «Уточнить у ИИ…».
- **Архив снимков** (кнопка в шапке, если настроен Orthanc). Папки с дисками лежат на сервере в `DICOM_DIR`. У каждой папки: «Импортировать» / «Импортировать заново», прогресс «импорт: 312 из 540 файлов…», результат «импортировано N файлов · КТ 2026-02-03». Импорт кладёт DICOM-файлы в Orthanc и привязывает исследование по дате и методу (КТ/ПЭТ к КТ, МРТ к МРТ); если такого исследования ещё нет, оно создаётся вместе с вехой «Снимки импортированы из <папка>. Заключение не приложено». Внизу ссылка «Открыть Orthanc целиком».
- **Открыть снимки** у привязанного исследования открывает просмотрщик (Stone Web Viewer) по адресу `<сайт>/orthanc/…`. Отдельного пароля браузер не спрашивает: пока открыт раздел «Снимки», МедКонтроль выдаёт короткий (8 часов) пропуск только для адресов `/orthanc`, и edge пускает к просмотрщику лишь с ним. Без входа в МедКонтроль просмотрщик закрыт даже для того, кто знает пароль Orthanc; «Выйти везде» и смена пароля закрывают и его. Если пропуск истёк, просмотрщик просит открыть снимки из МедКонтроля заново.
- **Сохранить срез**: выбор серии («КТ, 245 срезов»), кнопки «Предыдущий»/«Следующий» и ползунок (срезы идут сверху вниз по телу), окно «как в файле / лёгкие / мягкие ткани / кости / мозг». «Что на срезе? (ИИ)» — короткое объяснение уровня и структур простыми словами, без диагнозов. «Подпись (что на срезе)» и «Приложить к исследованию» сохраняют PNG к файлам исследования; после этого его видят «Отправить в ИИ» и вопросы к исследованию.

## История болезни

Хронология вех: операция, лучевая, гистология, контроль КТ/МРТ/ПЭТ, консультация, документ от врача, другое, оценка ИИ. У каждой — дата, название, комментарий, файлы (PDF или фото), и тон: «Хорошая новость», «Плохая новость» или «Контроль» (нейтральное). Тон окрашивает карточку в ленте и в отчёте врачу.

- **Новая веха**: «Дата», «Название», «Комментарий», тип, тон, файлы. «Изменить веху», «Удалить файл».
- **Загрузить документы** — пакетная загрузка. Выберите много файлов сразу: для каждого предзаполняются дата, тип и название из имени файла («КТ ОГК 03.02.2026.pdf» → 3 февраля 2026, «Снимок / заключение», КТ). Проверьте, поправьте, нажмите «Загрузить». На каждый файл создаётся своя запись; файлы типа «Снимок / заключение» (КТ, МРТ, ПЭТ-КТ, УЗИ, Рентген) заодно создают исследование в Снимках. До 50 файлов за раз, итог «Создано записей: N из M».

Все вехи с комментариями входят в профиль пациента, который видит ИИ.

**Текст документов.** У файла на карточке вехи видно, извлечён ли текст: из PDF с текстовым слоем он достаётся сразу при загрузке (и при пакетной загрузке, и из отчёта врача на приёме), для сканов и фото кнопка «Достать текст» распознаёт его прямо в МедКонтроле, без ИИ и без отправки файла. В буквах и цифрах возможны ошибки, поэтому такой текст помечен «распознан со скана». «Показать» открывает текст; «Кратко (ИИ)» делает аннотацию в 5–10 строк, «Подробно (ИИ)» переписывает документ дословно (сервис, который не видит картинки, получает распознанный текст); «В комментарий кратко» / «В комментарий полностью» добавляют текст в комментарий вехи. Извлечённые тексты читает ИИ: в профиле пациента у каждой вехи фрагмент документа (до 500 знаков), в развёрнутом досье (обновление анамнеза, вопросы к приёму) до 6 тыс. знаков на файл, в «Файле для ИИ» до 8 тыс. знаков на файл. Пока текст не извлечён, модель файл не видит, и на карточке об этом написано.

## Приёмы у врача

- **Новый приём**: «Дата», «Время», «Врач» (специальность или ФИО; у приёма без врача в карточке стоит «Врач»), «Где», «Заметка».
- Список «Приём» / «Прошедшие» со статусами: запланирован, сегодня, завтра, через N дней, ждёт отчёт, прошёл, отменён, отчёт есть.
- **Подготовить вопросы (ИИ)** / **Обновить вопросы**. Модель (основная) берёт профиль пациента и всё, что накопилось с предыдущего закрытого приёма (или за 90 дней, если такого нет): документы анализов, показатели вне нормы, динамика по маркерам, вехи, исследования, тревоги, оценки ИИ. Ответ по разделам: «Коротко о периоде», «Сказать врачу», «Спросить», «Показать или принести». Хранится вместе с контекстом («Что видела модель»). Если ответ обрезан по длине, в конце пометка — нажмите «Обновить вопросы».
- **Отчёт врача**: приложите файлы (фото или PDF), впишите «Кратко: что сказал врач, назначения», «Сохранить и закрыть приём». Файлы лягут в Историю болезни как консультация на дату приёма, приём получает статус «отчёт есть», напоминания прекращаются.

Напоминания в Telegram: за неделю (10:00), накануне (18:00), утром в день приёма (08:00); если приём прошёл, а отчёта нет — в 19:00 на следующий день и дальше каждый третий день, с кнопкой «Прошёл, отчёта не будет».

## Капельницы и инъекции

У каждого препарата в справочнике способ введения: «в/в капельно», «в/в струйно», «в/м», «п/к», «другое»; при записи сеанса он подставляется и его можно изменить («Как вводили»). Уколы в журнале помечены шприцем, в ленте называются «Укол: …», капельницы «Капельница: …». Способ введения виден в отчёте врачу, файле для ИИ и в контексте вопросов к ИИ.

- **Справочник капельниц**: при первом открытии заполняется из протокола лечения, если в протоколе есть препараты. Препараты есть в двух пресетах: в «Эндометриозе» это железа карбоксимальтозат 500 мг, в «Ленватинибе» витамин C в высоких дозах 25 г, глутатион 600 мг и гептрал 400 мг; у каждого заметка, зачем он. У остальных пресетов справочник начинается пустым. «Новый препарат»: «Название», «Коротко», «Доза» и единица, путь введения (по умолчанию «в/в капельно»), заметка. Неиспользуемые можно «Скрыть» и «Вернуть»; удалить можно только тот, по которому нет сеансов. У каждого — «сеансов: N, последний <дата>».
- **Записать капельницу**: «Препарат», «Дата», «Время», «Доза» (подставляется по умолчанию из справочника), «Минут», «Где / кто ставил», «Заметка», «Самочувствие во время и после».
- Журнал сеансов по датам; каждая капельница — событие в ленте «Сегодня».
- **Курсы**: «Курс» задаёт план: препарат, сколько сеансов, раз в сколько дней, дата старта, напоминать ли. Сеансы препарата сами попадают в активный курс, счётчик «3 из 10» растёт, при достижении плана курс закрывается. В день следующей капельницы по плану (и потом каждый третий день, пока сеанс не записан) приходит «💧 Курс …» в Telegram. Курс можно завершить, вернуть или удалить (сеансы остаются).
- **Тревога «IVC без G6PD»**: при записи капельницы витамина C в высокой дозе, если в МедКонтроле нет результата G6PD (глюкозо-6-фосфатдегидрогеназа), поднимается жёлтая тревога со ссылкой на загрузку анализа. Один раз.
- **Спросить у ИИ про капельницы**: вопросы по всему журналу.

Капельницы за 90 дней входят в профиль для ИИ, за период — в отчёт врачу («Капельницы за период»).

## Врачи и контакты

Ещё → «Врачи и контакты»: лечащие врачи, регистратура, процедурный кабинет — имя, кто это, где принимает, телефоны, почта, адрес и кабинет, сайт или личный кабинет, заметки (часы приёма, как записаться). Телефон и почта открываются одним касанием, закреплённые контакты сверху. В «Приёмах у врача» поле «Врач» подсказывает имена из контактов, а у приёма с таким врачом видна кнопка звонка. Контакты находятся поиском и попадают в экспорт.

## Доступ для ИИ-агентов (MCP)

Настройки → «Доступ для ИИ-агентов (MCP)». По умолчанию выключен. Включение — после предупреждения о том, какие данные увидит агент и куда они уйдут, с галочкой «я понимаю» и паролем. Дальше адрес сервера, токены агентов (название, «только чтение» или «чтение и запись», когда последний раз обращался, «Отозвать»), образец настройки клиента при создании токена и журнал обращений без данных. «Выключить доступ» отзывает все токены. В строке Настроек включённый доступ подсвечен. Подробно: [MCP.md](MCP.md).

## Помощник (чат с ИИ)

Круглая кнопка со значком ИИ в правом нижнем углу на всех страницах открывает разговор с ИИ. Если ИИ не подключён, кнопка появляется один раз: рассказывает, что даёт ИИ (разбор незнакомых бланков и заключений, комментарии, итог месяца, вопросы к приёму, этот чат), и ведёт в Настройки → «Помощник ИИ»; после «Понятно» прячется до подключения. Помощник видит профиль пациента (анамнез, терапию, анализы, вехи, дневник) и открытую страницу: на заметке её текст и файлы, на документе анализов его показатели, на остальных страницах название раздела. Отвечает быстрая модель; галочка «Подробно» включает основную модель. Разговоры сохраняются: «История» показывает прошлые, «Новый» начинает с чистого листа; у сообщений есть «Удалить». Ответы с форматированием (списки, выделение).

## Поиск по всему

Одно поле, результаты по группам: показатели анализов (ведут в динамику), препараты, вехи, документы (извлечённый текст и аннотации), заметки, снимки (заключения), документы анализов, приёмы, врачи и контакты, дневник, капельницы, ответы ИИ. Поиск полнотекстовый на русском со словоформами («очаг» найдёт «очагов»), плюс подстрока по названиям (латинские аббревиатуры вроде TI-RADS). В выдаче фрагмент текста с подсветкой совпадений; клик ведёт на карточку записи (вехи и снимки прокручиваются к нужной карточке). Индексы GIN в базе, так что поиск остаётся быстрым при росте данных.

## Заметки и исследование

Рабочая тетрадь о болезни: ссылки, статьи, мысли, новые научные данные, ответы других ИИ. Список с поиском по тексту и фильтром по тегам, закреплённые сверху. «Новая заметка» открывает редактор: заголовок, текст в Markdown (заголовки, списки, таблицы, ссылки), теги через запятую, ссылка (только `http://` или `https://`). Внешние картинки в тексте не загружаются сами, вместо них показывается ссылка; ссылки в тексте работают только `http(s)`, `mailto`, `dtc://` и якоря. «Импорт .md» принимает несколько файлов сразу: front matter (`title`, `tags`, `url`, `source`) и первый заголовок `#` становятся заголовком и тегами, остальное — текстом; так переносятся сохранённые чаты из Claude или ChatGPT. К заметке прикладываются картинки и PDF; картинку можно вставить в текст кнопкой в редакторе. Из PDF с текстовым слоем текст достаётся сразу при загрузке; для сканов и фото кнопка «Достать текст» распознаёт его прямо в МедКонтроле, без ИИ и без отправки файла. У файла видно «Текст: N тыс. знаков» и кнопки: «Показать»; «Кратко (ИИ)» делает аннотацию в 5–10 строк (что за документ, дата, главные выводы и цифры) и хранит её рядом с полным текстом; «Подробно (ИИ)» переписывает документ дословно (для сканов и фото); «Вставить кратко» / «Вставить полностью» добавляют раздел «## Файл: имя» в конец заметки. ИИ при разборе получает сначала краткое, потом полный текст. Каждая заметка — событие в ленте «Сегодня».

«Комментарий от ИИ» на заметке: основная модель читает заметку вместе с профилем пациента, извлечённым текстом файлов (до 60 тыс. знаков на файл, 120 тыс. суммарно, то есть отчёт NGS целиком; стоимость запроса растёт вместе с размером файлов) и картинками и отвечает по схеме «о чём заметка / что применимо ко мне / что не применимо или сомнительно / что спросить у врача»; дальше можно задавать уточняющие вопросы. Заметки (закреплённые и последние) попадают в «Файл для ИИ» и в экспорт архивом (`notes/*.md`).

## Дневник симптомов

Одна запись на день. Стрелки «Предыдущий день» / «Следующий день», быстрые «Сегодня» / «Вчера». Поля:

- самочувствие 1–5: плохо / так себе / нормально / хорошо / отлично;
- шкалы 0–3 (нет / слабо / умеренно / сильно) из протокола лечения (Настройки → «Протокол лечения» → «Шкалы дневника»). В справочнике 27 шкал: усталость, тошнота, рвота, диарея, запор, ладони и стопы, рот и горло, челюсть и ухо, изжога, сон, тревога, аппетит, онемение, сыпь, зуд, кашель, одышка, отёки, суставы, утренняя скованность, боль, головная боль, головокружение, тремор, судороги, кровоточивость, озноб. Каждый пресет включает свой набор (гипотиреоз: усталость, сон, запор, отёки, тревога, тремор; диализ: отёки, одышка, судороги, зуд…). Шкала, у которой в этот день уже есть значение, показывается, даже если её выключили в протоколе;
- «Температура», «Давление, верхнее / нижнее», «Вес, кг», «Пульс», «Шаги», «Заметка».

Справа графики «Давление» и «Вес» (пока запись одна, на графике точка), ниже «Последние записи»: строка на день со всем, что отмечено, включая слабые жалобы («усталость слабо»); «без жалоб» — только если ни одной жалобы нет. «Сохранить» отправляет только изменённые поля, поэтому давление, пульс и шаги, пришедшие из Apple Health или Telegram, не затираются. При сохранении проверяются правила тревог (см. ниже), но только для сегодня и вчера: старые дни, внесённые задним числом или из истории Health, тревог не поднимают. Запись можно сделать и из Telegram одной строкой (см. «Telegram»). Сводка за 14 дней (средние, максимумы, вес «было → стало») и последние три заметки входят в профиль для ИИ; за период — в отчёт врачу.

## Уведомления

Правила смотрят на каждый загруженный анализ и каждую запись дневника. Две степени: «Важно» (красное: связаться с врачом сегодня) и «Наблюдать» (жёлтое: следить, сказать на приёме). Пороги по анализам задаёт протокол лечения (Настройки → «Протокол лечения» → «Пороги тревог»), у каждого пресета свои. Ниже пороги «Общего контроля анализов»; пресеты под конкретное лечение меняют их и добавляют свои: например, «Гипотиреоз» следит за ТТГ (выше 10 или ниже 0,1), «Эндометриоз» за ферритином (ниже 15), «Трансплантация почки» за уровнем такролимуса. Правила по дневнику (давление, температура, шкалы на 3) общие для всех протоколов и заданы в коде.

| Что | Важно | Наблюдать |
|---|---|---|
| Нейтрофилы (NEUT#) | < 1,0 | 1,0–1,5 |
| Тромбоциты (PLT) | < 75 | 75–100 |
| Гемоглобин (HGB) | < 80 г/л | 80–100 |
| АЛТ, АСТ | > 3 норм лаборатории | |
| Билирубин, креатинин | | > 1,5 нормы |
| Калий | | > 5,5 или < 3,3 |
| Давление | ≥ 160/100 | ≥ 140/90 |
| Температура | ≥ 38 | |
| Диарея, ладони-стопы, тошнота на 3 | | да |

Значения перед проверкой приводятся к единицам правил (г/дл → г/л, мг/дл → мкмоль/л, клетки/мкл → ×10⁹/л). Одна и та же находка не поднимается дважды. На экране: «Открытые» с кнопкой отметить прочитанным и «Перепроверить» (прогнать правила по всем данным заново), ниже «Прочитанные». Новая тревога один раз уходит в Telegram в течение минуты, если она сработала за последние 3 дня. Поэтому загрузка старых PDF или истории Apple Health не присылает лавину сообщений: тревоги по старым анализам видны только на экране, а старые дни дневника тревог не поднимают вовсе.

## Отчёт для врача

Шапка отчёта: ФИО, дата рождения с возрастом и диагноз из «Настройки → Пациент и анамнез», затем период. Период: «3 месяца», «6 месяцев», «Год» или «С … По …». Состав отчёта настраивается галочками, есть пресеты «Новому врачу» (краткий анамнез, все вехи, снимки, ключевые анализы, дневник, аннотации документов), «Лечащему врачу» (только период: терапия, вехи, снимки, анализы, дневник, тревоги) и «Всё». Разделы: анамнез (кратко через быструю модель, 6–10 строк, результат кэшируется, или полностью), терапия, капельницы, вехи (за период или все), снимки и очаги, анализы (ключевые и вне нормы или все), самочувствие, тревоги, документы кратко (аннотации, сделанные кнопкой «Кратко (ИИ)»). Выбор запоминается в браузере. «Скачать PDF». Галочка «Вопросы к приёму первой страницей» (по умолчанию включена) ставит в начало список из раздела «Приёмы»: «Коротко о периоде», «Сказать врачу», «Спросить», «Показать или принести», пункты с квадратиками для галочек на приёме; берётся ближайший запланированный приём с подготовленным списком, иначе последний. Дальше: «Терапия» (препарат, доза, история изменений дозы, приём за период: принято / пропущено / пауза / без отметки), «Капельницы за период», «События за период», «Снимки и динамика очагов» (последнее исследование, таблица RECIST по датам, размеры целевых очагов), «Анализы» (показатель, последнее, дата, предыдущее, норма, единицы; амбер — вне нормы), «Самочувствие по дневнику» (дней умеренно/сильно и максимум по каждой шкале, давление, вес, заметки), «Тревоги за период». В подвале: «отчёт составлен автоматически из записей пациента, не заменяет медицинские документы». Отчёт не заменяет оригиналы документов; перед отправкой проверьте содержание и личные данные.

**Файл для ИИ.** На той же странице карточка «Файл для ИИ»: те же данные за период одним Markdown-файлом для приложения Claude, ChatGPT или другого ИИ (не через API, а как файл или текст в чате). В начале файла инструкция для модели (роль помощника, не врача; опираться на данные; ответы ИИ помечены). Разделы: анамнез, терапия и приём, все значения анализов по показателям с референсами (галочка «за всё время»), исследования с RECIST, вехи, капельницы и курсы, дневник самочувствия таблицей, тревоги, приёмы, заметки (галочка), прошлые ответы ИИ из МедКонтроля (галочка, выключена по умолчанию). «Скачать .md» или «Скопировать текст». Типичный размер 20–200 КБ.

## Настройки

Главная страница — короткий список разделов по группам, у каждого своя страница с кнопкой «‹ Настройки» (`frontend/app/settings/sections.ts`). Под названием раздела его состояние: «подключён» с зелёной точкой у «Напоминания в Telegram», «обновлён 12 окт.» у «Пациент и анамнез», «нужен ключ» у «Помощник ИИ». Если что-то сломано (бэкап с ошибками, сервис разбора PDF не отвечает, Telegram подключён не до конца), сверху появляется блок «Требует внимания» со ссылками; «не подключено» сломанным не считается.

- **Лечение:** Протокол лечения, Пациент и анамнез, Нормы анализов (живут в «Анализы → Нормы», сюда ведёт ссылка).
- **Связь и устройства:** Напоминания в Telegram, Apple Health, Помощник ИИ, Доступ для ИИ-агентов (MCP).
- **Вы:** Вход и защита, Язык, регион, часовой пояс, Архив всех данных.
- **Сервер:** Для администратора сервера: бэкапы и встроенные парсеры лабораторий. В настольной версии группа называется «Приложение», раздел «Служебное».

Отчёт для врача открывается из бокового меню на компьютере и из «Ещё» на телефоне, в Настройках его нет.

### Помощник ИИ

Сначала сервис: OpenRouter, Anthropic (Claude), ChatGPT (OpenAI), DeepSeek, Алиса AI (YandexGPT), GigaChat (Сбер) или «Свой адрес» — OpenAI-совместимый API, например локальная модель в Ollama или LM Studio (адрес и модель, ключ по желанию). У YandexGPT ещё каталог Yandex Cloud. Под полями одной фразой: куда уходят данные пациента (OpenRouter — только к провайдерам, которые не хранят данные; DeepSeek — серверы в Китае; свой сервер — данные не покидают сеть) и читает ли сервис PDF и картинки: DeepSeek, YandexGPT, GigaChat и свой адрес получают документы текстом (сканы и фото сначала распознаются прямо в МедКонтроле), а снимки КТ и МРТ им не отправить. «Подключить» сохраняет ключ и делает сервис текущим. Смена сервиса, адреса или ключа подтверждается паролем МедКонтроля: под кнопками появляется поле, кроме первых 15 минут после входа с паролем. Ключи хранятся на сервере, попадают в ночные бэкапы, но не в экспорт данных; ключ, заданный администратором в `.env`, важнее. Когда сервис подключён — «… · работает», «Проверить» (ответ под кнопкой) и «Сменить сервис или ключ» под катом.

«Дополнительно: модели и расход» (для тех, кто хочет выбирать сам):

- **Основная** модель — для больших задач: итог месяца, разбор заключений и PDF анализов, вопросы к приёму, анамнез.
- **Быстрая** — для коротких: комментарий к документу или исследованию, уточняющие вопросы.

Рядом пометка, откуда взята модель: «(выбрана здесь)», «(задана администратором)», «(по умолчанию)». «Проверить быструю», «Откуда идут запросы» (внешний адрес сервера: так проверяют, что запросы идут через VPN), расход токенов за два месяца, поиск модели OpenRouter с ценой за миллион токенов и пометкой «не читает PDF»; выбор применяется сразу, «по умолчанию» возвращает модель из настроек сервера. У сервисов кроме OpenRouter модели вписываются вручную («Основная модель», «Быстрая модель»).

### Пациент и анамнез

Карточка «Пациент»: ФИО, дата рождения, диагноз одной строкой. С них начинается отчёт для врача: под заголовком «Тестова Анна Петровна · 12 марта 1968 (58 лет)», ниже «Диагноз: …»; синяя шапка растёт вместе с длинным диагнозом. Имя и дату рождения ИИ не получает: в профиль для ИИ, файл для ИИ и MCP попадают только возраст и диагноз («Пациент: возраст 58 лет; диагноз (со слов пациента): …»). Карточка переносится «Архивом всех данных». Пока ФИО и диагноз пусты, страница отчёта подсказывает, где их заполнить.

Поле анамнеза — «мастер-контекст», который вы пишете сами (до 20 000 знаков): диагноз, стадия, операции, сопутствующие болезни, что принимаете. «Сохранить». «Обновить из истории (ИИ)» просит основную модель составить новую версию по текущему тексту и всем данным МедКонтроля; черновик показывается, и только после вашего «Сохранить» становится анамнезом. Ниже видно всё, что модель получает о пациенте при каждом запросе (см. «ИИ-функции»).

**История версий.** Каждое сохранение, которое меняет текст, становится версией (вручную, из истории ИИ, восстановлено). «Сравнить» показывает, чем текущий текст отличается от выбранной версии: зелёным добавленные строки, красным убранные. «Восстановить эту версию» возвращает старый текст, а текущий остаётся в истории.

### Нормы анализов

Анализы → «Нормы» (кнопка в шапке раздела) или Настройки → «Нормы анализов». Пол для норм (у гемоглобина, креатинина, ферритина, железа, гематокрита, эритроцитов, СОЭ, ЛПВП нормы у мужчин и женщин разные; без пола для них берётся норма из бланка) и список своих норм с кнопкой «Изменить». «Все показатели и их нормы» показывает весь справочник: какая норма действует и откуда она. Подробно: [REFERENCE-RANGES.md](REFERENCE-RANGES.md).

### Язык, регион, часовой пояс

Как показывать даты, время и числа: регион (из списка стран) задаёт значения по умолчанию, каждое можно поменять отдельно — формат даты (`02.11.2026`, `11/02/2026`, `2026-11-02`), 12 или 24 часа, первый день недели (по нему строится календарь приёма). Рядом с каждым вариантом пример. Единицы: анализы в СИ (ммоль/л) или традиционных (мг/дл, г/дл; в США по умолчанию), температура °C или °F, вес кг или фунты — пересчитываются только при показе и вводе, в базе остаётся СИ; пороги тревог протокола задаются в СИ. Здесь же часовой пояс (раньше задавался только в мастере первого запуска): по нему считаются дни приёма, дневник и напоминания. Изменения применяются сразу на всех экранах, данные в базе не пересчитываются. В выбранном формате идут и отчёт для врача, и выгрузки анализов, и сообщения бота, и тексты тревог. Язык интерфейса пока один, русский. Как это устроено: [I18N.md](I18N.md).

### Лаборатории

Настройки → «Для администратора сервера». Какие бланки разбираются без ИИ (сейчас МКНЦ, Хеликс, Хадасса и ДНКОМ), и что происходит с остальными: их разбирает модель по ключу, а вы проверяете строки. Ссылка на протокол добавления своей лаборатории и кнопка «Выбрать PDF бланка» для образца бланка (см. «Анализы → Загрузить»). Если сервис разбора PDF не отвечает, карточка так и пишет.

### Протокол лечения

Страница-обзор: название, статус («пресет автора», «пример, не проверен врачом», «свой»), «Сменить протокол» и четыре строки со своими страницами. На каждой своя кнопка «Сохранить» (закреплена внизу экрана); сохраняется весь протокол, части не затирают друг друга.

- **Сменить протокол.** Окно со списком пресетов и их описанием. Первым идёт «Общий контроль анализов»: он не привязан к болезни и препарату, подходит для любого долгого наблюдения и действует, пока протокол не выбран. Дальше пресеты под конкретное лечение: «Гипотиреоз (левотироксин)», «Эндометриоз (гормональная терапия)», «Ленватиниб», «Химиотерапия (цитостатики)», «Иммунотерапия (ингибиторы контрольных точек)», «Трансплантация почки (такролимус)», «Гемодиализ», «Метотрексат (ревматология)». Врач не проверял ни один пресет. «Ленватиниб» помечен «пресет автора»: этим протоколом пользуется сам автор программы, пороги он записал для своей терапии. Остальные, включая «Общий контроль анализов», помечены «пример, не проверен врачом». В окне ничего не отмечено заранее: загрузка заменяет действующий протокол. Пороги, заметки и тексты заменяются пресетом, а шкалы дневника, которые вы включили сами, остаются. После загрузки окно предлагает разовые шаги: «Создать режим приёма» (если основной препарат ещё не назначен) и «Добавить в справочник капельниц»; они же есть под катом на странице-обзоре.
- **Пороги тревог.** Каждое правило одной строкой: цветная точка, «Аланинаминотрансфераза > норма × 3», текст тревоги. Нажатие открывает окно: показатель, условие (`<`, `≤`, `>`, `≥`, «> норма ×» и «< норма ×» умножают границу действующей нормы: своей, из справочника или из бланка), значение, цвет (красная / жёлтая), текст тревоги с кнопками «значение», «единица», «граница нормы» вместо `{v}`, `{u}`, `{ref}`. «Добавить порог», «Удалить порог». При нескольких сработавших правилах для показателя берётся самое строгое.
- **Шкалы дневника.** Флажки по справочнику из 27 шкал, включённые сверху. Выключенная шкала не стирает записанное. Сюда же ведёт «Настроить шкалы» в дневнике.
- **Заметки к показателям.** Текст в карточке показателя блоком с названием протокола (например, что препарат делает с печенью).
- **Название и тексты для ИИ.** Название, вводная для ИИ (первой строкой в каждом запросе к модели), «как часто сдавать анализы» (в напоминании «давно не было анализов»).

Пресет «Ленватиниб» записан одним пациентом по своему опыту, остальные составлены по общедоступным описаниям побочных эффектов. Ни один не проверен врачом: сверьте пороги с лечащим врачом (см. `DISCLAIMER.md`).

### Apple Health

Давление с тонометра, вес с весов, пульс, температура и шаги из Здоровья на iPhone попадают в дневник за нужный день (давление берётся самое высокое за день, чтобы тревога не пропустила утренний скачок; вес последний; шаги суммируются; пульс покоя, а если его нет, средний), проходят правила тревог и дальше идут везде, где дневник: графики, отчёт врачу, файл для ИИ. Телефон присылает данные сам через приложение Health Auto Export (App Store): «Создать ключ» в карточке даёт ключ интеграции (показывается один раз, хранится только его хэш), в приложении настраивается автоматизация REST API на адрес `<APP_URL>/api/gateway/health/import` с заголовком `Authorization: Bearer <ключ>`. Карточка показывает последний приём данных и сколько образцов какого вида накопилось; «Отозвать» отключает ключ. Сырые образцы хранятся в `health_samples`, повторная отправка ничего не дублирует, а дневные итоги (шаги за день) обновляются. Давление с тонометра не понижает давление, введённое вручную за тот же день. Пульс и шаги сами по себе не создают день в дневнике: они дополняют дни, где уже есть запись, давление, вес или температура. Адрес `/api/gateway/health/import` принимает только ключ интеграции или сессию; остальные пути `/health` снаружи закрыты. История за прошлые годы заливается один раз из `export.zip` (см. OPERATIONS.md).

### Экспорт данных

«Скачать архив» собирает ZIP: `tables/*.json` (все таблицы, только ваши строки), `labs.csv` (все результаты анализов одной таблицей, открывается в Excel), `anamnesis.txt`, `notes/*.md` (заметки в Markdown), `files/` (PDF анализов, отчёты врачей, срезы), `manifest.json`, `README.txt`. Ключи входа (passkey), ключи сервисов ИИ, токен и chat id бота, хэши пароля и токенов в архив не попадают. Архив не зашифрован: это медицинские данные, храните как бумажную карту.

«Загрузить архив» на той же странице загружает такой ZIP обратно: переезд на другой компьютер, с сервера в настольную версию и обратно, восстановление из своей копии. Загрузка работает только в установке, где ещё нет записей (после мастера первого запуска), и просит пароль: архив ничего не смешивает и не перезаписывает. Переносятся все таблицы с записями, файлы (раскладываются в папку данных новой установки), анамнез, протокол лечения, часовой пояс, пол, язык и региональные настройки. Вход, пароль, passkey, ключи ИИ, Telegram и доступ для агентов остаются как настроены на новой установке: в архиве их нет. Архив до 2 ГБ; загрузка идёт потоком, без чтения в память.

### Вход и защита (passkey)

«Сменить пароль» (раскрывающийся блок в той же карточке): текущий пароль, новый дважды (правила те же, что при первом запуске: от 10 символов, не простой). Остальные устройства после смены просят войти заново. Если пароль задан администратором в `.env`, блок подсказывает, что сменить его может только он.

**Код восстановления пароля.** Мастер первого запуска сразу после пароля показывает код вида `XXXX-XXXX-XXXX-XXXX-XXXX` (один раз; «Скопировать», «Сохранить в файл», дальше только после галочки «Код записан или сохранён»). Хранится только его хэш. Забытый пароль: на экране входа «Забыли пароль?», код и новый пароль дважды. Регистр, пробелы и дефисы в коде не важны. После сброса все сессии завершаются, токены ИИ-агентов и ключ Apple Health отзываются, в Telegram приходит сообщение, а вместо использованного кода выдаётся новый. Неверный код считается как неверный пароль (блокировка после нескольких попыток). Код открывает вход и без ключа входа (passkey): это последний способ войти, когда потеряны и пароль, и телефон с ключом. Поэтому экран кода просит хранить его отдельно от телефона и компьютера. Карточка «Код восстановления пароля» показывает, есть ли код и когда создан; «Создать новый код» (с паролем) заменяет прежний. Если кода нет (установка старше этой функции), Настройки напоминают о нём в «Требует внимания». При пароле из `.env` кода нет: пароль меняет администратор.

Состояние: «только пароль», «два фактора», «второй фактор выключен» (когда `DTC_MFA=off`). «Название ключа» и «Устройство» — добавить ключ на этом устройстве. Добавление ключа требует пароль: украденной сессии не хватит, чтобы привязать чужой ключ. Удаление ключа тоже требует пароль. О каждом добавлении и удалении приходит сообщение в Telegram. «Выйти везде» завершает все сессии на всех устройствах. Под катом «Если все ключи потеряны» — как восстановить вход через администратора.

### Напоминания в Telegram

Токен бота и чат сохраняются с паролем МедКонтроля (кроме первых 15 минут после входа с паролем); когда бот или чат меняют, прежний чат получает сообщение об этом.

«Изменить время напоминаний»: время напоминания о приёме основного препарата, повтор (или «без повтора») и через сколько дней без анализов напомнить; всё по часовому поясу из «Язык, регион, часовой пояс». Значения, заданные в `.env` (`REMIND_DOSE_AT`, `REMIND_DOSE_AGAIN_AT`, `LAB_STALE_DAYS`), важнее: такие поля серые. Пока бот не подключён — три шага, активен только текущий: вставить токен от @BotFather, написать боту и нажать «Найти чат», выбрать свой чат («Это мой чат»). Бот запускается сразу, без перезапуска. После подключения — имя бота, что приходит (напоминание о приёме в 11:00, повтор в 20:00, проверка давности анализов) и «Отправить тест»; ответ появляется под кнопкой. В «Дополнительно»: заменить токен, выбрать другой чат, «Последние отправки». Токен и чат, заданные в `.env`, важнее и здесь не меняются. Сторожу (профиль `watchdog`) Telegram нужен в `.env`.

### Бэкапы

Настройки → «Для администратора сервера». Последний цикл по строкам: когда был бэкап, размер базы и файлов, копия на второй диск, копия в облако, проверка восстановления (в порядке / выключено / ошибка); при проблеме — список проблем. Как устроены бэкапы и где инструкция по восстановлению — под катом. Пока сервис не отчитался: «Сервис backup ещё не отчитывался». Ошибка бэкапа выносится наверх Настроек в «Требует внимания».

## Telegram

Бот отвечает только чату из `TELEGRAM_CHAT_ID`; сообщения из других чатов игнорируются и пишутся в лог. Путь к Telegram настраивается отдельно от ИИ: `TELEGRAM_PROXY=direct` значит напрямую, без VPN. Если задан прокси и он упал, gateway пробует прямой маршрут. Сторож шлёт тревоги так же: сначала по своему пути, при неудаче напрямую. Если Telegram недоступен, бот повторяет попытки с паузой до 5 минут.

**Что приходит:**

| Когда | Что |
|---|---|
| 11:00 (меняется в Настройках → Telegram), если приём за сегодня не отмечен | «💊 Диеногест 2 мг сегодня ещё не отмечен» с кнопками «✅ Принято» / «Пропустить» |
| время напоминания препарата поддержки, если он не отмечен | «💊 Левотироксин 125 мкг сегодня ещё не отмечен. утром натощак…» с теми же кнопками (без повтора) |
| 20:00 (там же; можно выключить), если всё ещё не отмечен | повтор с теми же кнопками |
| в течение минуты после новой тревоги (если она сработала за последние 3 дня) | «🔴 …» или «🟡 …» со ссылкой |
| приёмы у врача | за 7 дней в 10:00, накануне в 18:00, утром в 08:00; после приёма без отчёта — 19:00 через день, потом каждый третий день, кнопка «Прошёл, отчёта не будет» |
| 08:30 ежедневно | строка бэкапа за ночь |
| 09:30 | «⚠️ Бэкап: …», только если что-то не удалось или последний бэкап старше 36 часов |
| понедельник 10:00 | «🧪 Последние анализы были N дн. назад», если прошло больше `LAB_STALE_DAYS` (28) |
| 10:00 в день капельницы по плану курса, потом каждый третий день | «💧 Курс «IVC»: сделано 3 из 10, следующая капельница по плану сегодня» |
| сторож (контейнер `watchdog`) | «🚨 МедКонтроль не отвечает» после двух провалов подряд, «✅ снова отвечает», «⚠️ есть проблемы: …» при частичной деградации |

Каждое напоминание одного вида отправляется один раз в день (журнал в таблице `notifications`); окно отправки — три часа после назначенного времени, так что если сервер был выключен в 11:00, напоминание придёт позже, но до 14:00.

**Что можно писать боту:**

- «принято», «+», «да», «ок» — отметить основной препарат за сегодня; «+ левотироксин» (любое начало названия) — препарат поддержки; «пропуск», «-», «нет» — пропуск. Прежние «принял», «приняла» и «пропустил» бот тоже понимает. Ответ: «✅ Диеногест 2 мг сегодня принят в 10:42» или «уже отмечен: принят. Изменить можно в календаре».
- «статус», «?» — что с приёмом сегодня.
- **Дневник одной строкой**: «давление 135/85, усталость 2, вес 71, темп 37.1, самочувствие 4, сон плохо, тошноты нет». Понимает давление (и просто «140/90»), вес, температуру, самочувствие 1–5, любую шкалу из справочника (усталость, тошнота, диарея, ладони, горло, отёки, одышка, суставы, зуд, головная боль, «болит голова» и т. д.) с цифрой 0–3 или словом (нет, чуть, умеренно, сильно; слово без цифры считается как 2), «заметка: …». Начните со слова «вчера», чтобы записать за вчера. Строка меняет только названные поля, заметка дописывается к уже записанной, а не заменяет её. Ответ: «📝 Дневник за сегодня: АД 135/85 · 116 кг · усталость 2», плюс тревога, если давление или температура за порогом, и «Не разобрал и записал в заметку: …» для непонятых кусков.
- **PDF с анализами** (до 20 МБ), можно несколько подряд. Разбор идёт в фоне, бот тем временем отвечает на «принято» и кнопки. Знакомый формат — сразу в МедКонтроль, ответ «✅ Загружено: Helix, 3 сентября 2026. 24 показателя, вне нормы 3: ↑ АЛТ 78 Ед/л …», ссылка на документ. Незнакомый — «🤖 Формат лаборатории мне незнаком, разобрал через ИИ», список отклонений, «Сомнения модели» и кнопки «✅ Сохранить как есть» / «Отменить», плюс ссылка на построчную проверку на сайте. Дубликат — «Этот файл уже есть в МедКонтроле».
- Фото и скриншоты не принимаются: «Пока принимаю только PDF из личного кабинета лаборатории».
- Любой другой текст — подсказка «Я умею: …».

## ИИ-функции

Запросы идут к сервису, выбранному в Настройках → «Помощник ИИ»: OpenRouter (любая модель по id вида `anthropic/claude-opus-5`), Anthropic напрямую, ChatGPT, DeepSeek, YandexGPT, GigaChat или свой OpenAI-совместимый адрес (Ollama, LM Studio). Сервис и модели меняются без перезапуска. Сама программа бесплатна, запросы к платным сервисам оплачиваются у их провайдера по вашему ключу. Без ключа кнопки ИИ отключены с подсказкой «Ключ ИИ не задан», всё остальное работает. Ответы ИИ требуют проверки, особенно перед решениями о лечении.

**Какая модель за что:**

| Задача | Где | Модель |
|---|---|---|
| Разбор PDF анализов незнакомой лаборатории | Загрузить, Telegram | основная |
| Итог месяца по анализам | Анализы → «ИИ: итог месяца» | основная |
| Разбор заключения КТ/МРТ в структуру | Снимки → «Разобрать заключение» | основная |
| Вопросы к приёму | Приёмы у врача | основная |
| Обновление анамнеза | Настройки → «Обновить из истории (ИИ)» | основная |
| Комментарий к документу анализов | Документы | быстрая |
| Комментарий к исследованию | Снимки | быстрая |
| Уточняющие вопросы (документ, месяц, исследование, капельницы) | «Уточнить у ИИ…» | быстрая |
| «Что на срезе?» | Снимки → Сохранить срез | быстрая |
| Комментарий к заметке | Заметки → «Комментарий от ИИ» | основная |
| Текст скана или фото («Подробно (ИИ)»; для сервисов без зрения распознаётся без ИИ) | Заметки, История болезни | быстрая |
| Аннотация «Кратко (ИИ)» | Заметки, История болезни | быстрая |
| Краткий анамнез для отчёта | Отчёт для врача | быстрая |

По умолчанию основная — `anthropic/claude-opus-5`, быстрая — `anthropic/claude-sonnet-5` (через OpenRouter). У других сервисов свои модели по умолчанию (`gateway/src/lib/llmProviders.js`). Меняются в Настройках или через `LLM_MODEL` / `LLM_MODEL_FAST` в `.env`.

**Что видит модель.** В каждый запрос подставляется одна и та же вводная: модель помощник, а не врач, требование приводить каждую цифру с датой. За ней идёт вводная протокола лечения (Настройки → «Протокол лечения» → «Название и тексты для ИИ»), там описаны препарат и его побочки; диагноз модель узнаёт из анамнеза. Дальше — профиль пациента, собранный из данных МедКонтроля в момент запроса:

- анамнез из Настроек (помечен как мастер-контекст, при расхождениях модель должна уточнять, а не выбирать молча);
- все вехи болезни с заметками и фрагментами текста приложенных документов;
- снимки: сколько, последнее, оценка врача, сумма и RECIST по целевым очагам, заключение последнего исследования, размеры целевых очагов;
- терапия: препарат, доза, начало, история изменений дозы, приём за 30 дней (принято / пропущено / пауза / без отметки);
- поддерживающие препараты с дозой и правилами приёма;
- капельницы и инъекции за 90 дней;
- дневник за 14 дней: давление среднее и максимум, температура, вес, средние по шкалам, последние три заметки;
- открытые тревоги.

К профилю добавляется предмет запроса: документ с показателями и их прошлыми значениями, месяц с историей за полгода, исследование с очагами и предыдущими исследованиями той же зоны, приложенные картинки. Для обновления анамнеза — расширенное досье: все вехи полностью, все исследования, последние три значения ключевых маркеров, последний итог месяца.

**Диалог с ИИ.** Под любым комментарием ИИ можно задать уточняющий вопрос («Уточнить у ИИ…»). Диалог хранится, строка «Диалог с ИИ · N» сворачивает и разворачивает его (состояние запоминается в браузере для каждой записи). У каждой пары вопрос-ответ кнопка «Удалить», «Удалить диалог» стирает всю ветку по записи.

**«Что видела модель».** Под каждым ответом ИИ (комментарий, ответ на вопрос, вопросы к приёму) есть раскрывашка с точным текстом, который получила модель. Любую цифру в ответе можно сверить с тем, что ей дали. Контекст хранится в базе рядом с ответом и попадает в бэкап.

**Ограничения:**

- Это не медицинская консультация; модель сама об этом напоминает в конце ответов. Диагнозы и смена лечения — только врач.
- Модель видит сводку, а не сырые документы (кроме разбора PDF и заключений, где файл передаётся целиком). Если в МедКонтроле чего-то нет, модель этого не знает.
- Срезы КТ модель видит как отдельные картинки, не как объём; «Что на срезе?» — экскурсия по картинке, не чтение снимка.
- Ответы ограничены по длине (200–450 слов в зависимости от задачи; анамнез больше). Если ответ обрезан, показывается пометка.
- Для разбора PDF нужна модель с поддержкой файлов (в поиске моделей OpenRouter такие без пометки «не читает PDF»). Модели без структурированного вывода получают схему текстом — работает, но реже.
- Если провайдер модели не принимает адреса вашей страны, ИИ работает только через egress-прокси на VPN роутера. Если роутер сбросил политику, запросы падают по таймауту; «Откуда идут запросы» в Настройках → «Помощник ИИ» покажет домашний IP вместо адреса VPN.
- Ожидание ответа ограничено: OpenRouter 180 с (обновление анамнеза 420 с), Anthropic напрямую 240 с с одной повторной попыткой. При таймауте интерфейс пишет «Сервис не ответил вовремя (ИИ или парсер), попробуйте позже», при обрыве сети — «Нет связи с сервером».
- Через OpenRouter запросы уходят только к провайдерам, которые не хранят запросы и не обучаются на них (`data_collection=deny`).

## Что уходит наружу

Наружу данные идут, только если вы сами подключили один из этих сервисов:

- **Провайдер ИИ** получает текст запросов: профиль пациента и предмет вопроса, при разборе ещё и файл. Точный текст виден в «Что видела модель». Имя и дату рождения модель не получает, только возраст и диагноз.
- **Telegram** получает напоминания, тревоги и то, что вы пишете боту, включая отправленные ему PDF.
- **Облачное хранилище** получает зашифрованную копию бэкапов, если настроен третий ярус (см. «Бэкапы»).
- **Внешний ИИ-агент** (MCP, по умолчанию выключен) читает то, что разрешает его токен.

Образец бланка для новой лаборатории уходит только обезличенным и только по вашему действию (см. «Анализы → Загрузить»). Код открыт под AGPL-3.0, авторы не имеют доступа к вашим данным.

## Бэкапы

Три яруса, от быстрого к дальнему:

1. **Ночной дамп на сервере.** Сервис `backup` каждую ночь в `BACKUP_AT` (03:30) кладёт в `BACKUP_DIR/<дата_время>/` дамп базы `db.dump`, архив загруженных файлов `uploads.tar.gz` и копию `.env` (`env`, если файл есть). Хранится `BACKUP_KEEP` (14) последних.
2. **Второй диск.** Та же папка и папки с DICOM-дисками зеркалятся в `MIRROR_DIR` (rsync). Без `MIRROR_DIR` этого яруса нет, и карточка «Бэкапы» предупреждает, что копии лежат на том же диске.
3. **Облако.** Зашифрованная копия через rclone crypt в любое S3-совместимое хранилище; как подключить, в [OPERATIONS.md](OPERATIONS.md).

**Проверка.** Каждое воскресенье сервис восстанавливает свежий дамп в тестовую базу и сверяет число строк в анализах, вехах, приёмах и комментариях ИИ. Итог каждого шага пишется в `status.json`; его видно в Настройках → Бэкапы, он приходит утром в Telegram, а при проблеме (дамп не сделан, зеркало или облако не удались, проверка не прошла, последний бэкап старше 36 часов) — тревога в 09:30.

Снимки DICOM в дамп не входят: они лежат в `DICOM_DIR` и `ORTHANC_DIR` и защищены зеркалом на второй диск; Orthanc пересобирается импортом папок. Как восстанавливаться в трёх сценариях (откат данных, смерть диска, потеря сервера) — в [RESTORE.md](RESTORE.md).

**Сторож.** Контейнер `watchdog` (профиль compose `watchdog`) раз в 5 минут опрашивает сервис и пишет в Telegram, если МедКонтроль не отвечает или что-то работает с перебоями.

**Полный экспорт.** В любой момент все данные можно скачать одним ZIP: JSON всех таблиц, CSV анализов, файлы (см. «Экспорт данных»).

## Настольная версия

Тот же МедКонтроль как приложение для macOS и Windows, на одном компьютере и без Docker: окно Tauri, встроенный Node, база PGlite, данные в папке приложения. Готовых установщиков пока нет, приложение собирается из исходников ([DESKTOP.md](DESKTOP.md), «Как собрать»).

Только в серверной версии: Apple Health, архив снимков DICOM, ночные бэкапы, ключи входа (passkey), прокси для ИИ и Telegram. В интерфейсе они остаются с пометкой «только в серверной версии». Telegram-бот и напоминания работают, пока приложение открыто. Копию данных в настольной версии делает «Архив всех данных», он же переносит данные на сервер и обратно.

## Не сделано / отложено

- **Внешний аптайм-пинг**: сторож умеет пинговать `HEALTHCHECKS_URL`, но адрес на healthchecks.io / UptimeRobot нужно завести самому. Без него, если выключится сам сервер, снаружи никто не напишет.
- **Обновления**: Next.js 15.5 (поддерживаемая ветка с исправлениями безопасности) и React 19; переход на Next 16 — отдельной задачей.
- **«Выйти»** стирает токен только в браузере; отозвать все токены можно «Выйти везде».
- **Срезы по очагам**: картинки среза к каждому очагу и сравнение «было/стало» по картинке (отложено, надо продумать).
- **Режим «показать врачу»**: отдельный вход только на чтение с ограниченным сроком (отложено).
- **Парсеры лабораторий**: встроенные только МКНЦ, Хеликс, Хадасса и ДНКОМ (тесты на вымышленном тексте в `ingestion/tests`); всё остальное через ИИ с ручной проверкой. Новые добавляются по [LAB-PARSERS.md](LAB-PARSERS.md).
- **Образец бланка**: сервис приёма `samples/` написан, но адреса по умолчанию нет, поэтому отправка работает только там, где задан `LAB_SAMPLES_URL`.
- **Снимки**: Orthanc принимает только импорт из папок; сетевой приём DICOM выключен. Измерения очагов вводятся вручную (или из разбора заключения), по картинке не измеряются.
- **Один пользователь**: ролей, второго пациента и врача с отдельным входом нет.
- **Офлайн-режим** PWA — только заглушка «Нет связи с сервером», без кэша данных.
