# Что дальше

Короткий список того, что запланировано. Сроков нет: проект ведёт один человек в свободное время (см. [CONTRIBUTING.md](../CONTRIBUTING.md)).

## Ближайшее

- **Готовые установщики настольной версии** для macOS и Windows с подписью. Сейчас приложение собирается из исходников: [DESKTOP.md](DESKTOP.md).
- **Сервис приёма образцов бланков.** Экран «Образец бланка» уже готовит обезличенный текст; отправка включится, когда заработает адрес приёма (`LAB_SAMPLES_URL`). По присланным образцам появляются новые парсеры: [LAB-PARSERS.md](LAB-PARSERS.md).
- **Документация на английском**: сначала установка, обновление, восстановление и отказ от ответственности.
- **Вычитка английских медицинских текстов** носителем языка с медицинским образованием.

## Позже

- **Мобильное приложение-компаньон**: быстрый ввод с телефона в паре с серверной или настольной версией.
- **Парсеры бланков других стран.** Сейчас без ИИ читаются бланки четырёх российских лабораторий, остальные разбирает модель.
- **Темы оформления.**
- **Новые языки интерфейса**: словари устроены так, что язык добавляется папкой перевода, см. [I18N.md](I18N.md).

## Чего не будет

- Нескольких пользователей, ролей и входа для врача. МедКонтроль остаётся системой одного пациента.
- Диагнозов и назначений от программы. Она хранит и показывает историю, решения принимает врач.

Предложения и вопросы: [Issues](https://github.com/kubokot-tech/med-control/issues) или support@med-control.app.
