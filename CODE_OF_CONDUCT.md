# Code of conduct / Правила общения

People come to this project because they or someone close to them is ill. Keep that in mind.

- Be kind and specific. Criticise code and texts, not people.
- Do not share anyone's medical data, including your own, in issues, pull requests or screenshots. Use invented examples.
- Do not give medical advice here and do not ask for it. The project cannot check it, and a wrong answer can hurt someone.
- No harassment, insults or discrimination of any kind.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and block repeat
offenders. To report a problem write to support@med-control.app.

---

Сюда приходят люди, которые болеют сами или помогают близким. Помните об этом.

- Пишите по-доброму и по делу. Критикуйте код и тексты, а не людей.
- Не публикуйте ничьих медицинских данных, в том числе своих: ни в issue, ни в pull request, ни на скриншотах. Берите вымышленные примеры.
- Не давайте здесь медицинских советов и не просите их. Проект не может их проверить, а неверный ответ может навредить.
- Никаких оскорблений, травли и дискриминации.

Автор проекта может править и удалять комментарии, issue и pull request, которые нарушают эти правила, и блокировать
тех, кто нарушает их повторно. Сообщить о проблеме: support@med-control.app.
