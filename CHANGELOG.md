# История версий

## Не выпущено

## 0.3.0 — 13 ноября 2026

Первая публичная версия. Главное:

- **Для любой долгой истории лечения.** Тексты, значения по умолчанию, демо и протоколы больше не предполагают онкологию: первым идёт общий контроль анализов, есть примеры для гипотиреоза и эндометриоза.
- **Русский и английский.** Интерфейс, бот, отчёт для врача, выгрузки и ответы ИИ на выбранном языке.
- **Новый первый запуск**: пароль, затем пять шагов до первой пользы. Вход только по паролю.
- **Настольная версия** для macOS и Windows без Docker; пробные сборки без подписи.
- **Четыре лаборатории без ИИ**, распознавание сканов на месте, ручной ввод анализов.
- **Аудит перед публикацией**: исправления безопасности, сверка документации с кодом, лицензии сторонних компонентов.

Подробно:

- **Скрипты обслуживания.** `scripts/restore.sh` восстанавливает копию в новую базу и подменяет текущую только при успехе: подходит копия от более старой версии, а повреждённая копия не портит данные. `deploy.sh` и `backup.sh` работают без `.env`.
- **Безопасность, по итогам аудита.**
  - Смена сервиса ИИ, его ключа и адреса, а также бота и чата Telegram теперь просит пароль, если с ввода пароля прошло больше 15 минут. Украденная сессия больше не может незаметно перенаправить данные. О смене бота или чата приходит сообщение в прежний чат.
  - Новый пароль: не короче 10 знаков, не из одних цифр, не клавиатурный ряд и не из списка частых. Уже заданные пароли работают как раньше.
  - Резервная копия больше не содержит секрет сессий: после восстановления все входят заново. Если облачная копия не зашифрована, об этом предупреждают журнал, карточка бэкапов и утреннее сообщение.
  - Вложения из загруженного архива с необычным типом скачиваются, а не открываются в браузере.
  - Сервис приёма образцов отбрасывает управляющие символы; свой адрес ИИ нельзя направить на службы самого стека в обход проверки; запросы без входа не могут занять память большими телами; защита от перебора считает адреса IPv6 подсетями.
- **Скачать настольную версию** можно прямо из README: ссылки на установщики для Mac (Apple и Intel) и Windows и инструкция, как запустить неподписанную сборку. Установщики прикладываются к каждому выпуску автоматически.
- **Настольная версия для macOS запускается после скачивания.** Приложение подписано без сертификата разработчика: раньше macOS называла скачанную сборку повреждённой. Идентификатор приложения теперь `app.med-control.desktop`; данные остаются на месте, войти придётся заново.
- **Настольная оболочка на двух языках.** Меню, окно и сообщения приложения на русском на русской системе и на английском на остальных. Приложение называется MedControl латиницей. Пробные установщики для macOS и Windows собирает GitHub Actions по ручному запуску.
- **Документация сверена с кодом перед выпуском**: первый запуск, обновление с 0.2.0 и откат, четыре лаборатории, часовой пояс бэкапов и сторожа, облачная копия у любого провайдера. Ярлык «готовый пресет» заменён на «пресет автора»: ни один пресет не проверен врачом.
- **Отказ от ответственности на английском**: [DISCLAIMER.en.md](DISCLAIMER.en.md).
- **Для публичного репозитория**: [SECURITY.md](SECURITY.md) (как сообщить об уязвимости), [правила общения](CODE_OF_CONDUCT.md), шаблоны issue, [планы](docs/ROADMAP.md). Скачиваемые файлы на русском называются `medcontrol-…`, а не `dtc-…`.
- **Отметка приёма без мужского рода**: «Принято», «Пропустить», «принято», «пропущено»; бот понимает прежние слова.
- **Новое демо и два протокола.** Демо теперь про эндометриоз с железодефицитной анемией: гормональная терапия, курс железа, УЗИ с размерами кист в динамике, дневник боли. Скриншоты пересняты. Добавлены протоколы-примеры «Гипотиреоз (левотироксин)» и «Эндометриоз (гормональная терапия)». Экран «Снимки» больше не говорит только про КТ и RECIST: очаги можно вести по размеру без онкологической оценки.
- **Онбординг, шаг ИИ.** Для всех сервисов одна мягкая формулировка: прочитайте правила перед подключением, в них могут быть ограничения. Для OpenRouter добавлен совет запретить модели, которые обучаются на запросах. В README появился адрес для поддержки проекта.
- **Новый первый запуск.** Сначала только пароль и язык, затем пять шагов: кто ведёт историю и диагноз, протокол лечения, анамнез текстом или из документа, подключение ИИ с пошаговыми инструкциями для OpenRouter, Claude, ChatGPT и GigaChat, первые анализы. Любой шаг можно пропустить, а в конце видно, что уже загружено и какие значения вне нормы.
- **Бланки ДНКОМ разбираются без ИИ:** кровь, биохимия, гормоны, онкомаркеры, аутоантитела. Заодно исправлено: нормобласты больше не попадают в ряд эритроцитов, а холестерин ЛПВП и ЛПОНП и сывороточное железо узнаются в таком написании.
- **Нормы в выгрузках.** Если у показателя задана только верхняя или только нижняя граница (АЛТ, АСТ), в PDF и Excel теперь видно «≤ 40», а не прочерк. В единицах США значения больше не показываются с лишним знаком: креатинин 1,03, а не 1,029.
- **Брендинг в PDF.** В отчёте для врача и сводной анализов знак МедКонтроля в шапке, а внизу каждой страницы строка, что документ подготовлен в МедКонтроле, со ссылкой на med-control.app.
- **Демо на английском.** `DEMO_LANG=en scripts/demo.sh reset` ставит ту же вымышленную историю на английском, с единицами и форматами США. Каталог узнаёт английские названия основных показателей.
- **Боковое меню на компьютере.** История болезни, дневник симптомов, капельницы и инъекции, приёмы у врача и отчёт для врача теперь видны сразу, а не в «Ещё». Под знаком написано название. На телефоне всё как раньше.
- **Вход только по паролю.** Пользователь один, поэтому логина больше нет ни на экране входа, ни в мастере. На существующих установках пароль и ключи входа работают как раньше. Переменная `DTC_LOGIN` больше не нужна.
- **Дата в выгрузке Excel.** На листе со всеми результатами дата была на день раньше настоящей, если сервер работает не в UTC. Исправлено. В отчётах легенда теперь называет цвет верно: значения в норме синие, а не зелёные.
- **Новый знак МедКонтроля: каменный акведук.** Дорога через долину, сложенная камень за камнем. Знак стоит в боковой панели, логотип с названием на языке интерфейса на экранах входа, первого запуска и «нет сети», новые значки приложения, вкладки браузера и настольной версии. Исходники и правила: [docs/brand/README.md](docs/brand/README.md).
- **Всё, что пишет программа, теперь на английском, если выбран English.** Для русского языка ничего не изменилось.
  - Бот: команды, справка, напоминания, тревоги и уведомления о входе. Дневник одной строкой и «принял» работают на обоих языках при любой настройке, например `pressure 135/85, fatigue 2, weight 71`. Единицы берутся из настроек, можно написать их прямо: `weight 160 lb`, `temp 101.3 f`.
  - Отчёт для врача, выгрузки анализов (Excel, PDF, CSV, JSONL), файл для ИИ-приложений с пометкой «AI answer, not fact», README в архиве всех данных и имена файлов. CSV на английском: разделитель запятая, дробная часть через точку.
  - ИИ отвечает на английском и видит профиль на английском. Подсказки вынесены в словари. Бланки и заключения на русском читаются по-прежнему, значения переносятся как напечатаны.
  - Инструменты MCP и подписи в их ответах на языке владельца токена.
  - Ошибки на английском экране теперь на английском: раньше они показывались по-русски.
  - Код первого запуска в журнале получил метку `SETUP_CODE`, русская строка осталась.
  - Сообщения сторожа на английском включаются в `.env`: `WATCHDOG_LANG=en`.
  - Записи пациента и уже полученные ответы ИИ не переводятся. Таблицы в архиве хранят записи как в базе.
- **Английский на всех экранах.** Показатели и единицы анализов, шкалы дневника, пресеты протокола, тревоги, лента, модальности, способы введения и частота приёма теперь на языке пользователя. Если сменить язык, уже записанные тревоги и заголовки ленты тоже переходят на него; данные пациента остаются как введены. Для русского интерфейса ничего не изменилось.
- **Английский интерфейс.** В Настройках → «Язык и регион» и в мастере первого запуска можно выбрать English, название программы тогда MedControl. Новая установка сама открывается на языке браузера.
- **Новый README и скриншоты.** README теперь сначала отвечает, подойдёт ли программа и как её попробовать: раздел «Подойдёт ли вам», демо в начале установки, предупреждения до установки, полный список функций в конце. Скриншоты пересняты в новом оформлении, добавлены отчёт для врача и история болезни.
- **Документация сверена с кодом.** Исправлены устаревшие описания экранов, кнопок, переменных окружения, маршрутов и команд. В `docs/OVERVIEW.md` появились образец бланка, настольная версия, что уходит наружу; в `docs/OPERATIONS.md` раздел о дополнительных службах; в `DISCLAIMER.md` образец бланка и внешний ИИ-агент. В `.env.example` добавлены недостающие переменные и убраны неиспользуемые.
- **ChatGPT и DeepSeek через VPN-прокси.** Контейнер `egress` отказывал им с ошибкой 403: их адресов не было в списке разрешённых. Теперь они там есть. Чтобы правка заработала, пересоберите контейнер: `docker compose up -d --build egress`.
- **Новые публичные тексты.** Копилайн «Вся история лечения под рукой», новое начало README с историей автора, раздел про другого врача, экран входа «История лечения — целиком.». Весь продукт больше не называется дневником: это касается заголовка приложения, мастера первого запуска, подвала отчёта для врача и экспортов. Экран входа теперь с описанием, кнопка «Войти в МедКонтроль». Как мы говорим о продукте: [docs/BRAND-VOICE.md](docs/BRAND-VOICE.md).
- **Сервис приёма образцов бланков** для сайта МедКонтроля (`samples/`): принимает обезличенный текст, читать и удалять можно только по ключу, старые образцы удаляются сами. Перед каждым выпуском образцы проверяются командой `node scripts/lab-samples.mjs`.
- **Образец бланка для новой лаборатории.** Если вашей лаборатории нет в списке, приложение готовит текст бланка без личных данных: незнакомые слова закрыты, цифры случайные, сам PDF никуда не уходит. Текст можно прочитать, поправить и скопировать. Отправка включится, когда появится адрес приёма (`LAB_SAMPLES_URL`).
- **Какие лаборатории разбираются без ИИ, теперь видно на вкладке «Загрузить»:** список названий под полем загрузки, из того же источника, что и в настройках. Обновлена подсказка про сканы.
- **Вкладки анализов на телефоне** больше не обрезаются: они компактнее, а на самых узких экранах активная вкладка сама прокручивается в видимую область.
- **Тихие вехи и тихий режим.** На главной появляются «100 дней терапии», «Год с начала терапии», «100 дней приёма подряд»; их можно скрыть или выключить в Настройках → «Пациент и анамнез». Две недели после вехи с отметкой «плохая новость» серия дней и вехи не показываются, вернуть их можно одной кнопкой.
- **Фото или инициалы того, о ком дневник,** на главном экране. Фото добавляется в Настройках → «Пациент и анамнез», уменьшается прямо в браузере и в ИИ и отчёт врачу не попадает; в архив данных попадает.
- **Спокойнее формулировки.** Вместо счётчиков вины вопросы: «Отметить приёмы за неделю?», «Как прошёл приём 3 ноября?» (и в боте). Незагруженный отчёт врача больше не обведён красным, как опасность. На новой установке нет «0 дней приёма подряд».
- **Пустые экраны** рассказывают, что здесь появится и с чего начать: единый вид с иконкой, тёплые тексты без привязки к онкологии; на «Сегодня» и в «Документах» сразу кнопка загрузки анализов. В дневнике убрана подсказка «форма слева», неверная на телефоне.
- **Главный экран стал человечнее.**
  - Приветствие по времени суток и по имени: «Добрый вечер, Анна». В Настройках → «Пациент и анамнез» появились «Как обращаться на главном экране» и «Дневник ведёт: сам пациент / близкий человек»; для близкого вопрос звучит «Как мама сегодня?».
  - «Как вы сегодня?»: самочувствие в дневник одним касанием, без формы; остальное в дневнике не трогается.
  - «Хорошая новость»: недавняя веха, отмеченная как хорошая, и показатель, вернувшийся в норму. Приложение показывало в основном проблемы, теперь и хорошее; карточку можно скрыть.
- **Интерфейс теплее.** Фон и серые стали тёплыми, синий акцент остался. Иконки разделов получили свои мягкие оттенки. Кнопка помощника ИИ, комментарии ИИ, кнопка «Принял…» и серия дней приёма отмечены вторым, тёплым цветом (ягодная фуксия); на данные анализов он не попадает.
- **Исправлено в оформлении:** падение показателя больше не окрашено как хорошая новость (для гемоглобина или тромбоцитов это не так), подсказка графика не красит рост красным, а падение зелёным; страница загрузки анализов и справка по показателю перешли на общую палитру; янтарный «вне нормы» и бледные подписи стали контрастнее (WCAG AA); убрана зелёная подсветка полей, оставшаяся от старой темы; в подсказке загрузки упомянута Хадасса.
- **PDF читает сам gateway, Python-сервис в запасе.** После того как JS-движок стал давать тот же текст, что pypdf, он стал движком по умолчанию (`PDF_ENGINE=js`), и сервер с настольной версией разбирают бланки одинаково. Контейнер `ingestion` больше не запускается сам: он в профиле compose `python` (`COMPOSE_PROFILES=python` и `PDF_ENGINE=python` в `.env`). Если в `.env` осталось `PDF_ENGINE=python`, а сервис не запущен, gateway читает PDF сам; уже запущенный контейнер после обновления можно убрать: `docker compose stop ingestion && docker compose rm -f ingestion`.
- **Исправлено: настольная версия не разбирала бланки МКНЦ и теряла строки больших бланков Хеликса** и отдавала их ИИ. Её движок чтения PDF раскладывал текст по-своему; теперь он повторяет алгоритм серверного (pypdf) и даёт тот же текст на всех проверенных бланках МКНЦ, Хеликса и Хадассы.
- **Отчёт врачу, выгрузки анализов, бот и тексты тревог** показывают даты и числа в формате из Настроек → «Язык и регион». Исправлено: время в строке о бэкапе и в пометке о восстановлении анамнеза считалось по Москве, теперь по часовому поясу пользователя.
- **Подготовка к переводу интерфейса:** все тексты экранов вынесены в словари `locales/<язык>/<раздел>.json` (ICU, `use-intl`), TypeScript проверяет ключи, тест не даёт добавить новые русские строки прямо в код. Для пользователя ничего не меняется; английский перевод — отдельным решением.
- **Сканы и фото документов распознаются без ИИ, прямо в МедКонтроле.** Кнопка «Достать текст» у вложения теперь работает и для сканов и фото: текст распознаётся на этом компьютере или сервере (Tesseract), файл никуда не отправляется. Сервисы ИИ, которые не видят картинки (DeepSeek, YandexGPT, GigaChat, своя модель), теперь получают сканы и фото бланков распознанным текстом, поэтому разбор незнакомых бланков и заключений работает и с ними. Распознанный текст помечен: в буквах и цифрах возможны ошибки. Снимки КТ и МРТ по-прежнему видят только сервисы с поддержкой картинок.
- **Исправлено: разбор снимков и документов через Claude API не работал.** Помощник Anthropic SDK для структурного ответа требует zod 4, а с zod 3 падал ещё до запроса (`Cannot read properties of undefined (reading 'def')`). Gateway переведён на zod 4.6.7, заодно закрыта уязвимость высокой опасности в zod 3 (исчерпание памяти при проверке огромных массивов). В zod 4 `.partial()` подставляет значения по умолчанию, поэтому схема правки отметки переписана: без поля «тон» он остаётся прежним, а не становится «нейтральным».

- **Помощник ИИ и вход без жаргона**: в «Помощнике ИИ» сначала ключ и «Проверить», модели, расход и сеть — под «Дополнительно»; вместо «.env» — «задано администратором сервера»; восстановление входа при потере ключей — под катом. Бэкапы показаны по строкам в формате пользователя.
- **«С чего начать»** на экране «Сегодня» после первого запуска: протокол, анамнез, помощник ИИ, Telegram, у каждого зачем он нужен. Мастер теперь ведёт на «Сегодня». Под названием раздела Настроек его состояние, сверху «Требует внимания», если что-то сломано.
- **Настройки по разделам**: вместо 13 карточек на одной странице — список разделов (Лечение, Связь и устройства, Вы, Сервер), у каждого своя страница. Telegram подключается по шагам, сообщения появляются рядом с кнопкой, инструкция Apple Health сворачивается, когда данные пошли. Бэкапы и парсеры лабораторий — в разделе для администратора. Нормы анализов — в «Анализы → Нормы». Карточки «Отчёт для врача» и «Профиль и данные» убраны (отчёт — в меню «Ещё»).
- **Нормы анализов**: у показателя одна норма вместо своей у каждой лаборатории. По умолчанию справочник МедКонтроля для взрослых (54 показателя, для части отдельно мужские и женские), для любого показателя можно задать свою норму или выбрать «как в бланке» (экран динамики → «изменить норму», Настройки → «Нормы анализов», там же пол). Норма бланка у результата сохраняется. Отметки, сводная, лента, тревоги протокола, тексты для ИИ, отчёт и выгрузки считаются от действующей нормы; нормы с одной границей («до 5») теперь тоже дают отметку «выше». Миграция 032, [docs/REFERENCE-RANGES.md](docs/REFERENCE-RANGES.md).
- **Язык и регион** (Настройки и мастер первого запуска): регион задаёт формат даты, 12/24 часа, разделитель дробной части и первый день недели, каждое можно поменять. Все даты и числа интерфейса идут через общий модуль `shared/format.js` (миграция 031: `users.locale`, `users.prefs`). Мелкие изменения вида: даты без «г.» в конце («2 ноября 2026»), заголовки месяцев в сводной анализов — «нояб. 26». Образ gateway тоже собирается из корня репозитория.
- **Общие словари** `locales/`: тексты ошибок API теперь в `locales/ru.json`, одна копия вместо двух. Образ frontend собирается из корня репозитория; в контекст сборки попадают только `frontend/` и `locales/` (раньше туда уходили и локальные `node_modules`). Правила для языков и форматов: [docs/I18N.md](docs/I18N.md).
- **Удаление исследования** теперь удаляет и извлечённый текст его файлов, как удаление вехи; раньше текст оставался в поиске.

## 0.2.0 — 2 ноября 2026

- **Шкалы дневника из протокола**: справочник из 28 шкал, набор задаёт протокол лечения; новые шкалы хранятся в `symptom_entries.scales` (миграция 029). Личные шкалы «челюсть и ухо» и «изжога» больше не показываются по умолчанию.
- **Пресеты-примеры**: химиотерапия, иммунотерапия, трансплантация почки (такролимус), гемодиализ, метотрексат.
- **Лаборатории**: реестр встроенных парсеров с текстовым контрактом, список в Настройках, тесты парсеров в CI, протокол добавления лаборатории `docs/LAB-PARSERS.md`.
- **Такролимус** в каталоге показателей (`TAC`, нг/мл): бланки с концентрацией такролимуса распознаются, в пресете трансплантации пороги и пояснение.
- **Расписания приёма**: каждый день, по дням недели или раз в N дней (миграция 030). Напоминания, серия, календарь, отчёты и профиль для ИИ учитывают дни без приёма. Пресет «Метотрексат» получил недельный режим.
- **Безопасность compose**: внутренняя сеть для базы, Orthanc и парсера PDF; `no-new-privileges` и сброс capabilities; файловая система только для чтения у gateway, парсера, фронтенда, edge и сторожа; закреплённые версии базовых образов.
- **Надёжность**: gateway больше не падает, когда Postgres разрывает простаивающее соединение.
