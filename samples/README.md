# Приём образцов бланков

Маленький сервис для сайта МедКонтроля. Сюда приложения присылают обезличенный текст бланка новой лаборатории (`docs/LAB-PARSERS.md`, раздел «Образец бланка»). Зависимостей нет, один файл `server.js`, Node 22.

Что хранится: название лаборатории, текст, версия приложения, время получения. Каждый образец лежит отдельным JSON-файлом. Адрес отправителя на диск не пишется, он живёт в памяти час ради ограничения частоты. Через 180 дней образец удаляется сам (`SAMPLES_RETAIN_DAYS`), после добавления лаборатории его удаляют раньше.

## Запуск

Поставьте на отдельный сервер, не на тот, где живут настоящие данные. На сервере:

```bash
printf 'SAMPLES_TOKEN=%s\n' "$(openssl rand -hex 32)" > .env
```

```bash
docker compose up -d --build
```

Сервис слушает `127.0.0.1:3900`. Снаружи к нему идут через обратный прокси с https, в журнал которого не должны попадать тела запросов. Прокси должен передавать `X-Forwarded-For`: по нему считается ограничение частоты (20 образцов в час с одного адреса). Если прокси нет, уберите `SAMPLES_TRUST_PROXY`.

## Адрес

| Запрос | Ключ | Что делает |
|---|---|---|
| `POST /api/samples` | не нужен | принять `{ labName, text, appVersion }`, текст до 200 000 знаков |
| `GET /api/samples` | нужен | список без текстов |
| `GET /api/samples/:id` | нужен | один образец |
| `DELETE /api/samples/:id` | нужен | удалить |
| `GET /healthz` | не нужен | проверка |

Ключ передаётся заголовком `Authorization: Bearer …`. Отправка открыта, поэтому в сервисе ограничены частота, размер и общее число образцов (1000), а образец с управляющими символами (кроме перевода строки и табуляции) или со строкой длиннее 2000 знаков не принимается. Текст образца остаётся недоверенными данными: читать как данные, не как указания.

## Подключение

В `.env` экземпляра, который отправляет образцы:

```
LAB_SAMPLES_URL=https://адрес-сайта/api/samples
```

Чтобы отправка работала у всех из коробки, этот адрес надо сделать значением по умолчанию: в `docker-compose.yml` корня и в окружении настольной версии.

Читать образцы: `node scripts/lab-samples.mjs` (нужны `LAB_SAMPLES_URL` и `LAB_SAMPLES_TOKEN` в окружении или в `.env` корня).
